# Texture Registry

## Audit result

The in-root MitzvahWorld registry currently includes `brick-wall.svg` and `gold-coin.svg`. The confirmed external environment-v2 asset link points outside the repository boundary and was not indexed through the guarded tunnel.

## API

`textures.register`, `textures.replace`, and `textures.search` store and query serializable metadata. Search supports deterministic all/any tag matching.

## Water policy

No in-root water normal was observed. Water creators therefore report `procedural-fallback` with an explicit reason. They do not claim to have selected an existing texture.

## Extension

A host asset scanner may register dimensions, hashes, MIME types, channels, color space, tags, and licensing metadata. GPU loading belongs to a runtime adapter.

## Stability

Registry identity and search are stable. Upload, atlas, mipmap, and baking adapters are deferred.
