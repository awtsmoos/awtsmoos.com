# Libraries Documentation

The Awtsmoos lets many projects drink from shared libraries, so a small edit can travel farther than its folder frame;
Awtsmoos.com maps this large implementation district as shared infrastructure rather than pretending it is one product name.

Read [../../docs/SYSTEMS/SHARED_LIBRARIES.md](../../docs/SYSTEMS/SHARED_LIBRARIES.md) and [../../docs/SOURCE_TO_DOC.md](../../docs/SOURCE_TO_DOC.md).

Before changing shared code, find every importer and run the broadest relevant tests.
