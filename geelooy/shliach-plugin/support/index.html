Support

Awtsmoos Shliach is published by Jacob Kaufer. Use the existing Awtsmoos contact form for plugin support, account questions and access, correction or deletion requests.

Open the contact form

Help us reproduce the problem

Put “Awtsmoos Shliach” in the subject. Include the plugin version, the action, the time, the expected result and the actual error. For a device problem, say whether your authorized device agent is online. For a privacy request, identify the account and data category without including a password, bearer token or pairing secret.

The contact form asks for your name and email so a reply can reach you. It returns a reference after accepting a message. Keep that reference for follow-up. No fixed response time is promised.

Before retrying an action

Check the returned job or operation state before repeating a command, write, deletion or publish request whose result is uncertain. Ask the tunnel for the current action schema and instructions. OAuth sign-in should happen on the Awtsmoos authorization page; never paste credentials into chat.
