01 / LIVE READER

Words assembled by the font

The DOM contains encoded private-use characters. Browser selection copies encoded data; normal accessibility, copying, niqqud and cantillation are not supported.

02 / GEOMETRY

Three-part Aleph

Each piece is a separate clipped glyf outline. Switch strokes on or off; together they occupy one letter width. Other Hebrew letters use two to four fragments.

03 / TRANSPORT

What the browser receives

Randomized aliases change on each build and each occurrence. The payload contains neither the original Hebrew passage nor a decoding table.

			05 / ADVERSARIAL AUDIT
Can the downloaded font reveal the text?

			
Loading the threat-model evidence…

			
Yes, in principle. An attacker can inspect the downloadable cmap, group aliases with identical glyph IDs, compare font outlines and apply OCR. Text length, spaces and punctuation remain observable. This raises some scraping costs; it is not encryption or an access-control boundary.
