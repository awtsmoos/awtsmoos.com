# Current → Goal Visual Upgrade Plan

User compared the current screenshot against the ideal shot board. The current runtime still shows a sparse room, unstable framing, black void above the set, and weak staging. The goal is not to delete the engine. The goal is to add careful fallbacks and production polish while preserving all currently working character faces, mouths, limbs, and props.

## Non-breaking principles

1. Existing renderers stay alive.
2. Every rewritten file is full-file rewritten.
3. New values are clamped.
4. Missing state gets safe defaults.
5. Camera safety overrides aesthetic ambition.
6. Scene richness must come from authored layers, not procedural chaos.
7. Facial expression improvement must be additive and consumed by existing Stable renderer.

## Target result

- No black bars from camera overshoot.
- Subjects centered in mobile safe frame.
- Room fully dressed: shelves, books, window, plants, table, curtains, framed wall details, dishes, props.
- Shots vary between wide, two-shot, close-up, insert, reaction, and final group.
- People have natural idle, talking gestures, expressive face poses, and better hands.
- Props carry story function.
