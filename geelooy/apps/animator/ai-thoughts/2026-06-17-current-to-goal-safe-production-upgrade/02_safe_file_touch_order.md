# Safe File Touch Order

1. Camera safety files.
2. Backdrop / room art file.
3. Default scene beats and scene data.
4. Facial expression bridge/library.
5. Limbs/body/hands polish.
6. Props library/builder polish.
7. Verification files.
8. Package verify scripts.

The reason: if camera and backdrop are fixed first, later character and prop details will be visible instead of being cropped away or lost in black void.
