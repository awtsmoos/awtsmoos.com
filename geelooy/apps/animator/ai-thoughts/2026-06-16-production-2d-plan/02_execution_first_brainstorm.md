# Execution First Brainstorm

Now we do it. The first implementation pass will be a coherent slice, not all forty-five files if the existing render stack rejects that scale. The Awtsmoos demands truth: inspect renderer integration, then build a production 2D healthy-lunch base that actually appears, not a theoretical museum.

## Focus

- HealthyLunch modular scene becomes default.
- Stage coordinates use table/floor anchors, not city roofs.
- Events include food actions.
- Renderers exist for kitchen/food/effects.
- Existing managers are adapted only where necessary.
- Full verify must pass.

## Possible failure paths

1. Scene manager ignores custom scene style and still draws city.
2. Prop manager cannot render food types.
3. Event compiler drops custom action fields.
4. Camera processor zooms too hard despite scene cameras.
5. Mobile UI seal still hidden by browser bar.

## Immediate inspection before writing

Read scene manager, prop manager, dialogue compiler, event processor, and camera processor. Then write second and third execution plans before file rewrites.
