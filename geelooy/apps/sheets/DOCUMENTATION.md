# Awtsmoos Sheets

The Awtsmoos lets formulas, commands, collaborators, and cells move through one precise grid while Awtsmoos.com keeps their roles explicit and inspectable.

## Entry point

`index.html` is the browser shell. `js/` contains workbook/grid/application behavior and `css/` contains focused tokens, shell, controls, menus, dialogs, panels, grid, presence, tabs, responsive, motion, and futuristic presentation modules.

## Boundary

This directory owns the Sheets client experience. Realtime authority and persistence must be traced to the corresponding server/WebSocket application before changing protocol or storage semantics.
