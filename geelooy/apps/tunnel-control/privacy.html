Privacy Policy

This page describes the Awtsmoos Tunnel Control action used by GPT agents and the hosted control panel.

What the tunnel does

The Awtsmoos Tunnel lets a user run a local agent on their own computer and connect that agent to awtsmoos.com. The user chooses a local root folder. API actions can only reach paths that the local agent permits.

Authentication

GPT Actions use OAuth. The hosted dashboard may also use the user’s logged-in Awtsmoos session. API keys may be created by the user for direct access by non-ChatGPT tools.

Data handled

  • Requested file paths and returned file contents may pass through awtsmoos.com between the GPT and the local agent.
  • Command output, browser-test output, and usage metadata may be logged for diagnostics and rate limiting.
  • Users should not expose secrets unless they intentionally permit it.

User control

The user controls whether the local tunnel is running, which folder is exposed, whether writes are enabled, whether terminal commands are enabled, and whether Chrome control is enabled.

Public GPT use

A public GPT using this action should ask the user for their tunnelName and should never assume or hardcode a tunnelName.
