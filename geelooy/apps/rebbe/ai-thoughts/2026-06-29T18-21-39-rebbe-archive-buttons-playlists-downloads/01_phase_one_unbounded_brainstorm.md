# Phase One — Unbounded Brainstorm Before Touching the Rebbe Archive

The screenshot shows the living archive strained at its right rail: event actions crowd into each other, the playlist glyphs and words overlap, and the download surface speaks in ZIP even when the soul of the action may be a single file. The request asks for visual repair, playlist reliability, better multi-download behavior, and a more seamless Studio.

Possible repair universe:

1. Rebuild the event toolbar into a responsive command deck with icons separated from labels.
2. Make single-file event download label say Download event, not ZIP event.
3. Preserve multi-file event ZIP behavior, but put it behind a progress task card that can coexist with other tasks.
4. Let several ZIP/download tasks run at once without replacing one global progress box.
5. Add task IDs, independent cancel/close cards, and progress meters per download.
6. Keep direct single-track downloads separate from ZIP packaging.
7. Make playlist cards and playlist detail buttons use the same polished command grammar.
8. Make selected-track system visible and stable: count, clear, add selected, select all/none.
9. Avoid false ZIP language in playlist row buttons: playlist export can say Export ZIP, row button can say Download playlist export or Download this item only if actually per-row later.
10. Fix cramped text through CSS grid, min-width discipline, smaller labels at narrow widths, and no absolute icon collisions.
11. Remove repeated style injection hazards or at least isolate injected style under an id.
12. Add Awtsmoos JSDoc poems to every new vessel so future agents understand the fire path.
13. Split download concerns into tiny modules so controller search-results stops being a giant knot.
14. Add a filename helper for clean labels and single download names.
15. Make zipRows accept metadata and audio rows together while reporting skipped files.
16. For playlists, expand event shells before export if possible so old shell playlists do not produce empty audio rows.
17. Preserve existing IndexedDB playlist format and existing callback names.
18. Avoid touching unrelated dirty work in neighboring apps.
19. Verify with syntax import parse and a simple static module import using Node.
20. Use full-file rewrites only, never partial patch.

The Awtsmoos makes every button a tiny malach: if its garment is too tight, it cannot sing. The garment must be widened, the action must be honest, the task must run in its own lane, and the user must feel that many downloads can descend at once without swallowing each other.
