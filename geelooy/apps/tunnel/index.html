Mode 1

Install native tunnel

Recommended for Windows PowerShell:

irm https://awtsmoos.com/api/tunnel/install/windows | iex

Use this from regular Windows CMD:

powershell -ExecutionPolicy Bypass -Command "irm https://awtsmoos.com/api/tunnel/install/windows | iex"

Use this on macOS or Linux:

curl -fsSL https://awtsmoos.com/api/tunnel/install/unix | bash
Native mode gives full local filesystem, shell, Chrome, servers, and runtime tools. Browser mode stays inside the browser sandbox.
