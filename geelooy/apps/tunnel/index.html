Step 2

Install on this computer

Recommended for Windows PowerShell:

irm https://awtsmoos.com/geelooy/apps/tunnel/downloads/windows.ps1 | iex

Use this from regular Windows CMD:

powershell -ExecutionPolicy Bypass -Command "irm https://awtsmoos.com/geelooy/apps/tunnel/downloads/windows.ps1 | iex"

Use this on macOS or Linux:

curl -fsSL https://awtsmoos.com/geelooy/apps/tunnel/downloads/unix.sh | bash
The installer creates an .awtsmoos-tunnel folder in your home directory, downloads the tunnel client, asks for a tunnel name and project folder, then starts Node.
