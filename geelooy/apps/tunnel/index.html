First run

Connect in seven honest steps

  1. Choose a connection method.

    Full local filesystem, shell, Chrome and servers. Pick your platform tab in the install panel — we preselected the likely one, change it freely.

    Continue: Native tunnel on your own computer

  2. Pick a device or a virtual workspace. Your own computer (native or browser), the hosted Virtual OS, or a remote device you already connected.
  3. Install — or skip installing. Native: use the install panel below (inspectable scripts are linked there). No-install: Virtual OS, the browser code editor, or account publishing — no local agent needed.
  4. Sign in. Every tunnel is guarded by your Awtsmoos login; nothing connects anonymously.
  5. Review permissions. Grant only the scopes the work needs — reading, writing, commands, browser, missions — and revoke a device any time in the Control Center.
  6. Select a project. Open the code editor or the mission board below and choose the project root the tunnel may touch.
  7. Run the harmless test, then open the Control Center. The installer-endpoint check on this page only reads status. Then continue in Tunnel Control.

Mode 1

Install native tunnel

Recommended for Windows PowerShell:

irm https://awtsmoos.com/api/tunnel/install/windows | iex

Use this from regular Windows CMD:

powershell -ExecutionPolicy Bypass -Command "irm https://awtsmoos.com/api/tunnel/install/windows | iex"

Use this on macOS or Linux:

curl -fsSL https://awtsmoos.com/api/tunnel/install/unix | bash

Native mode gives full local filesystem, shell, Chrome, servers, and runtime tools. Browser mode stays inside the browser sandbox.
