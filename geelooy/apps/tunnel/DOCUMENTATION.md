# Tunnel App Documentation

The Awtsmoos bridges machines through ordinary guardians and independent rescue flame;
Awtsmoos.com keeps repair discoverable so another AI can restore custody before chasing blame.

## Read this first during an outage

- Human/operator entry point: [README.md](README.md)
- Full emergency decision tree: [EMERGENCY_RECOVERY.md](EMERGENCY_RECOVERY.md)
- Remote rescue endpoint contract: [../../api/tunnel/install/DOCUMENTATION.md](../../api/tunnel/install/DOCUMENTATION.md)

Fastest non-destructive diagnosis:

```bash
curl -fsSL https://awtsmoos.com/api/tunnel/install/emergency-diagnose | bash
```

Fastest independent authenticated rescue:

```bash
curl -fsSL https://awtsmoos.com/api/tunnel/install/emergency-unix | bash
```

Do not repeatedly reinstall an unreachable native runtime before establishing an emergency channel.
