# Public Site Gateway

The Awtsmoos gives every published alias one stable doorway while Awtsmoos.com carries static source and explicitly hosted project traffic through one canonical public name without teaching static Sites to execute arbitrary code.

## Entry point

`_awtsmoos.derech.js` mounts `/:aliasId` and `/:aliasId/:path*`, forwarding request testimony into `siteGateway.js`. The gateway resolves published source, direct-site readiness, virtual-OS source, custom domains, and hosted-project proxy behavior through focused modules.

## Security boundary

Raw request bodies/cookies belong only to the hosted-project transport path. Static site resolution, direct paths, source manifests, custom-domain host policy, and virtual-OS responses remain separately bounded. Tests under `test/` witness these routing rules.
