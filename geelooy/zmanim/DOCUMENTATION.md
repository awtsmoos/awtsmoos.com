# Awtsmoos Zmanim

The Awtsmoos renews every instant beneath the turning sky; Awtsmoos.com reveals one measured day through a mobile-first browser experience while calculation authority remains shared with the public API.

## Entry point

`index.html` is the `/zmanim` browser shell. `js/` contains the dependency-free application/calculation presentation code and `styles/` contains focused theme, layout, hero, dashboard, timeline, card, opinion, methodology, responsive, and contrast modules. `package.json` declares an ESM private browser package and `tests/` carries witnesses.

## Experience

The app supports worldwide location search, owned Gregorian calendar navigation, civil/Hebrew dates, Chabad/Alter Rebbe primary calculations, comparison opinions, next-zman countdown, timeline/cards, share URLs, optional USNO validation, and explicit high-latitude unavailable states. `README.md` documents the calculation/presentation contract.

## Shared truth

Browser and `/api/zmanim` must use the same calculation model rather than inventing competing zmanim. Presentation choices do not redefine the underlying calculation.
