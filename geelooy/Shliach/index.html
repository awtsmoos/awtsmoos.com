Step 1 · Install

Install the tunnel.

One command opens the secure doorway between your machine and Awtsmoos. Running it again refreshes or restarts the tunnel — your identity is preserved.

macOS / Linux

curl -fsSL https://awtsmoos.com/api/tunnel/install/unix | bash

Windows PowerShell

irm https://awtsmoos.com/api/tunnel/install/windows | iex

After connection

Every serious mission becomes visible.

A connected agent should inspect missionVisibilityList, register or link its work, and publish operational planning passes 1, 2 and 3 directly into the tunnel. Local AI-thought folders are only archival mirrors.

Pass 1

Reveal the reality

Record the inspected system, broad implementation shape and concrete verification targets.

Pass 2

Narrow the work

Publish the actual file/feature map, dependencies and safe execution boundaries.

Pass 3

Commit the contract

Publish the final operational plan, then keep mission progress live while executing it.
