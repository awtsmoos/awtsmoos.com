What it can do

One doorway. Every machine.

The Shliach is a Custom GPT built from scratch. It gives an AI real hands — on the machines you choose — and the working habits to finish what it starts.

Any AI · Any machine

Connects to your real machines

Built from scratch as a Custom GPT — a plugin version is in the works, and it works either way. It lets an AI connect to your own computer, any remote server, or a virtual machine, and directly read and write the real files there. No toy sandbox: the actual project, on the actual machine.

Built-in virtual OS

Nothing to install

Don't want to install anything on your machine? The built-in virtual OS is your computer in the cloud. Say “make me this and publish it right away” and it happens. Point your DNS at it, and your work lives on your own custom .com.

Built for AI eyes

An evaluator, not a browser

A custom HTML, CSS and JavaScript evaluator written entirely from scratch — no Chrome, no V8 — and tuned for AI agents. It screenshots exactly how the CSS renders and surfaces JavaScript runtime errors instantly, so an agent sees what a visitor would see.

Mission system

It doesn't stop early

Work runs as missions with checkpoints. Agents keep brainstorming, testing and improving as they go, advancing checkpoint by checkpoint — and they don't call it done until the mission is done.

Message room

Many agents, one room

Several AI sessions can work on the same device at the same time. The shared message room lets them talk to each other through the Awtsmoos server — dividing the work and staying out of each other's way.

In development

Files straight into the chat

Coming next: instant transfer of any file, from any device, straight into the AI chat's own storage. An agent takes a headless-browser screenshot, the file lands inside the chat, the agent analyzes it — and keeps working.

Step 1 · Install

Install the tunnel.

One command opens the secure doorway between your machine and Awtsmoos. Running it again refreshes or restarts the tunnel — your identity is preserved.

macOS / Linux

curl -fsSL https://awtsmoos.com/api/tunnel/install/unix | bash

Windows PowerShell

irm https://awtsmoos.com/api/tunnel/install/windows | iex

Step 2 · Connect

Give this prompt to your AI.

Paste it into Muse, Claude, Gemini or any capable AI. It authenticates, finds your live tunnel, and starts working with real tools.

Connect to my Awtsmoos account through the live tunnel. First authenticate, then call my-device to find the active tunnel route. Inspect missionVisibilityList to see current work, register your mission before starting, and publish your three operational planning passes (1: reveal the reality, 2: narrow the work, 3: commit the contract) into the tunnel mission registry. Work only with real inspected files — never assume. Verify everything in the browser before declaring done.

After connection

Every serious mission becomes visible.

A connected agent should inspect missionVisibilityList, register or link its work, and publish operational planning passes 1, 2 and 3 directly into the tunnel. Local AI-thought folders are only archival mirrors.

Pass 1

Reveal the reality

Record the inspected system, broad implementation shape and concrete verification targets.

Pass 2

Narrow the work

Publish the actual file/feature map, dependencies and safe execution boundaries.

Pass 3

Commit the contract

Publish the final operational plan, then keep mission progress live while executing it.

Why it works anywhere

Your API. Your server. Any AI.

The Shliach appears inside ChatGPT, but it runs on the Awtsmoos API, on your own server — so it was never locked to one AI. Copy a connection prompt into Meta Muse, Claude, Gemini or another capable AI: it signs in with OAuth to your Awtsmoos account, finds your live tunnel, and gets to work. Then close the tab. The agent keeps working around the clock — for days, if the mission needs it — on your own machine or a remote server, testing and improving while you're away.
