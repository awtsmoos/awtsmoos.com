Agent eyes

What your agent can see, instantly.

Every version gives the agent the same four ways to see a page. The difference is how invisibly it reads.

page.html

Raw HTML

The page's live HTML, serialized as the browser sees it — doctype and all. Pages are long, so the agent reads it in chunks (32,000 characters at a time) and pages through.

page.dom

The DOM, resolved

The parsed DOM tree as JSON: each element's tag, meaningful attributes, its own text, and its children — scripts and styles skipped, depth and node count capped so the answer stays small.

page.summary

A compact summary

Title, headings outline, meta description, the page's text, word count, and the first links and forms — a few kilobytes the agent can read in seconds instead of a full dump.

page.elements

What to click

Every clickable and selectable element on the page — links, buttons, inputs, selects — each with a stable selector that selects exactly that element, so the agent knows what to click and how to address it.

Stealth · Unrestricted

The page doesn't know

The Unrestricted version reads through the debugger, outside the page's JavaScript context: no injected script, no content script, no navigator.webdriver flag, no network request — and the readers only read, never change anything. The page has nothing to detect. The only trace is Chrome's “debugging” banner, visible to you, not to the page.

Stealth · Minimal & Standard

Honest limit

These two run the same pure readers from the page itself (a content script, or an injected script on your click). The reads never change anything, but the page can in principle detect that an extension is present. Use Unrestricted when the page must not know.

One hard limit, built into the relay: any single message over 64 KiB is refused, so large answers are chunked and capped — raw HTML in 32,000-character pages, the DOM tree to 200 nodes, the elements list to 150. The agent asks for the next chunk when it needs more; nothing is silently cut.

The live connection

How the agent connects.

The extension does not open a port on your computer and it does not store a password. It reaches out to Awtsmoos.com, and your agent meets it there.

  1. Your agent creates a pairing code. The agent — signed in to its Awtsmoos account — asks the server for a 6-character code. The code lives for ten minutes and pairs exactly one browser.
  2. You type the code into the extension. Open the extension popup, enter the code, and press Connect. The code itself is the authorization — no token ever sits in the extension.
  3. The relay forwards messages between them. The Awtsmoos realtime server (the same one that powers the site's live features) passes JSON back and forth between the agent and your browser. It never stores the messages and never reads them.
  4. Either side can end it. Close the popup connection, or let the code expire, and the pairing is gone. If the agent disconnects, the room closes; if your browser disconnects, you can rejoin with the same code while it is still valid.

The connection runs over wss://awtsmoos.com/api/shliach/relay, application shliach-browser, version 1. Once paired, the agent sends JSON commands and gets JSON back: page.html, page.dom, page.summary and page.elements to see the page; page.read, page.click, page.fill and page.navigate to work it; page.evaluate and page.screenshot (Unrestricted only); network.start, network.stop, network.download and network.stream (Unrestricted only). Only the Unrestricted version can attach the debugger and stream network traffic; Minimal and Standard work through the page itself and never see the network.

Install

Three steps, in Chrome.

The extension is not in the Chrome Web Store. You install it yourself, in under a minute.

  1. Download a version above. Pick the one that matches what you are comfortable granting. Check the SHA-256 on this page against the file you downloaded, if you like.
  2. Unzip it. Open the ZIP and keep the folder it creates — that folder is the extension.
  3. Load it unpacked. Open chrome://extensions, turn on Developer mode (top right), press Load unpacked, and choose the folder. The extension icon appears in your toolbar.
  4. Pair it. Ask your agent for a pairing code, click the extension icon, type the code, and press Connect.
