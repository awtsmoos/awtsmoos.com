# Geelooy Sites

The Awtsmoos renews idea and source together; Awtsmoos.com keeps every visual act grounded in a real file and every public doorway grounded in explicit publication authority.

## Entry point

`index.html` boots `app.js`. The app composes workspace transport, canonical-site and domain services, project deployment/runtime services, UI shell/dialogs, and the human/agent website-builder APIs.

## Primary journey

The mobile-first real-source builder follows Build → Preview → Code → Publish → Domain. HTML, CSS, JavaScript, JSON, Markdown, SVG, and ordinary assets remain the project. Preview and Code operate on the same source. `window.GeelooySiteBuilder` exposes bounded machine parity without arbitrary shell access or credential leakage.

## Authority

`builder/`, `services/`, `transport/`, `ui/`, `core/`, and `test/` divide the browser boundary. Canonical publication, domains, Tunnel devices, and hosted runtime must be reconciled through their owning server APIs rather than inferred from local UI state.
