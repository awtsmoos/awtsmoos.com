## Performance Budget

The Awtsmoos creates without waste; the Awtsmoos.com corridor must remain lighter than a framework router.

- No package or framework dependency.
- Each new JavaScript module below 120 physical lines.
- Initial kernel target below 18 KB uncompressed total.
- Cache at most six parsed route records in memory.
- One active fetch; superseded navigation is aborted.
- Prefetch only exact supported routes and skip when `saveData` is true or effective connection is `2g`/`slow-2g`.
- No persistent HTML cache, Service Worker, or IndexedDB in this pass.
- No route-wide MutationObserver.
- No repeated shell construction.
- No implicit script evaluation.
- A cache hit still runs lifecycle, history, title, focus, and scroll contracts.
- Repeated navigation test target: listener counts stay constant and cache remains bounded.
