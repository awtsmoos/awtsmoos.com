# Phase Two — Corrective Design and Performance Plan

The Awtsmoos gives each visible responsibility one vessel. The repair will not add another theme; it will connect the existing composer markup to a single live Home owner and remove unnecessary startup work.

## Visual correction

1. Add a canonical Home composer manifest to the active Home stylesheet chain.
2. Rewrite the composer shell, fields, actions, and responsive files as one coherent compact system.
3. Use persistent labels as small metadata above premium controls, never as loose plain text.
4. Keep the advanced destination panel closed and inert until explicitly opened.
5. Make the collapsed state a useful single-row desktop composer and a deliberate stacked mobile composer.
6. Give every foreground and background explicit ownership.
7. Use calm cyan/magenta accents only for focus, publish, and selected states.

## Performance correction

1. Remove the ambient pointer effect from initial Home boot unless a real visual dependency requires it.
2. Defer the live-feed module until the initial page has painted.
3. Remove duplicate resize and global click listeners where the same state can be CSS-driven or delegated once.
4. Eliminate expensive gradients, shadows, and animations from repeated feed cards and form controls.
5. Measure resource count, transferred bytes, DOM size, long tasks, and time to composer readiness.
