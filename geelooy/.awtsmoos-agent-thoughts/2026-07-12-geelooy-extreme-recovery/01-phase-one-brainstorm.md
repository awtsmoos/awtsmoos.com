# B"H — Phase One: Recover the Lost DNA

## Product direction
The application should not resemble a conventional enterprise dashboard. The old Geelooy header worked because it was peculiar: a compact floating vessel, a visible B"H jewel, a living alias dropdown, a direct Mail portal, and a menu that felt like a small constellation. The recovery will keep that identity and amplify it.

## Header possibilities
1. Restore the `awtsmoosificationalisticaticalism` header class as the canonical global shell.
2. Use one floating capsule instead of a full-height rail.
3. Place the B"H home jewel at the left as a luminous physical object.
4. Put the old glass search lens in the center on desktop.
5. Mount the actual modular profile dropdown directly in the header.
6. Keep Mail and menu as unmistakable icon portals.
7. Expand the menu into a vivid route constellation with large touch targets and short descriptions.
8. Keep the five-item dock only on mobile, where it adds real value.
9. Preserve native links and forms so the visual spectacle never weakens reliability.

## Search possibilities
- Restore the animated pink-violet search orb and translucent pill from `HEAD:style/geelooy-system/search.css`.
- Turn the header search into a command-search hybrid: typing filters route suggestions; Enter submits to Heichelos search; a dedicated Torah result remains visible.
- Make the Home search larger and more cinematic while retaining the same visual grammar.
- Use a conic-gradient ring, pulsing glow, chromatic cursor response, and a results sheet that feels like a portal opening beneath the input.
- Avoid generic grey borders, flat placeholders, or unrelated color accents.

## Global visual possibilities
- One coherent palette: ink-black, plasma cyan, ultraviolet, and controlled hot magenta.
- Mail may use a dedicated gold/cyan/emerald subsystem because the historical Quantum Mail identity already established it.
- Add animated aurora bands, perspective grids, spectral edges, layered shadows, glass depth, and occasional scanlines.
- Keep all motion short and purposeful; extreme visuals must not create slow navigation.
- Use strong typography scale, iconography, and shape, not just gradients.

## Email possibilities
- Restore the December 2025 “Awtsmoos Quantum Mail” visual language.
- Remove the light “calm application frame” and the explicit “no spectacle” override.
- Remove redundant internal Mail navigation; global unusual header handles site navigation.
- Preserve the current sender categories, folders, profile dropdown, search, grouped threads, chat, composer, and APIs.
- Make the sender sidebar resemble an illuminated communications deck.
- Make thread cards easier to scan with sender name, subject, snippet, time, category, and active-state edge.
- Make the chat pane a deep void with gold outgoing bubbles, cyan incoming edges, readable content, and a fixed holographic composer.
- Restore scanlines, particles, wormhole loader, goo filter, and command modal without allowing effects to cover controls.
- Replace the current 500ms 720-degree thread transition with a fast 180–220ms dimensional transition.

## Risks
- The global shell currently assumes rail and topbar classes; every content offset must be rewritten together.
- Profile dropdown styles must remain viewport safe when mounted in both the global header and Email sidebar.
- Email has several imported visual layers; the recovery must establish one final authoritative entry order.
- Search suggestion and command behavior must not conflict with page-specific forms.
- The user explicitly dislikes blandness, so partial tweaks would repeat the failure.

## Phase-one file universe
- Shared shell renderer, route map, command/search behavior, header and menu styles.
- Home markup and search composition.
- Global tokens, background, surfaces, responsive rules.
- Profile-dropdown visual modules.
- Email HTML, layout, chat transition, all visual CSS entry modules, and contract tests.
