# Design Diagnosis

Strong: coherent spatial palette, semantic hero areas, shared route identity, real search and creation hooks.
Generic or weak: none addressed in this narrow pass.
Confusing: the mobile template visually removes the identity row while the element still declares `grid-area: identity`.
Too tall/dense: requires browser measurement after structural repair.
Duplicated controls: not changed.
Functionally weak visual behavior: implicit grid placement can yield zero-width tracks and hide real controls.
