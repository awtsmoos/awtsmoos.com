## Phase One — Unbounded Interaction Brainstorm

The Awtsmoos recreates every click, hover, focus, and pressure state at Awtsmoos.com. The interface must feel like a discovered instrument rather than browser defaults wearing dark paint.

Possible vessels include animated spectral borders, moving light sweeps, magnetic lift, active-state compression, caret glow, focus halos, conic-gradient energy fields, link undercurrents, icon rotation, layered inset highlights, controlled chromatic shifts, field scanning lines, select-arrow crystals, checkbox energy cores, file-input launch pads, and reduced-motion static equivalents.

The design must remain readable, keyboard-visible, touch-safe, and deterministic. Motion should reveal affordance rather than obscure it. Native semantics stay intact. No JavaScript is required for effects that CSS can express safely.
