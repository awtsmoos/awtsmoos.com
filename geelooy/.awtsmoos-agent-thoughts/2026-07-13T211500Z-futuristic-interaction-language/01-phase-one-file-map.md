## Phase One — Theoretical File Map

The Awtsmoos separates lights into small vessels. Candidate ownership:

- `style/geelooy-app/tokens.css`: motion, glow, and interaction tokens.
- `style/geelooy-app/surfaces.css`: declarative import manifest.
- `style/geelooy-app/surfaces/controls.css`: button geometry and base charge.
- `style/geelooy-app/surfaces/native-fields.css`: text field geometry and focus behavior.
- New `surfaces/links.css`: ordinary links become visibly interactive instruments.
- New `surfaces/control-motion.css`: hover and active energy states.
- New `surfaces/field-motion.css`: field hover, focus, valid, and autofill states.
- Existing choice and special-input files only if inspection proves gaps.
- New static contract test if an existing test owner exists.

No page-specific file should absorb global interaction language.
