## Improvement Pass

The Awtsmoos renews the plan by testing its boundaries. These improvements refine the first architecture.

1. Keep context data plain and serializable.
2. Normalize every optional string centrally.
3. Validate actions as anchors with labels and hrefs.
4. Default to a truthful `unknown` state, never a plausible fiction.
5. Keep breadcrumb length bounded.
6. Preserve one page `h1`; the ribbon title must not become another `h1`.
7. Use `aria-labelledby` for the ribbon region.
8. Use a visible state label plus a semantic data attribute.
9. Hide the ribbon entirely when no deep-route context is published.
10. Publish blocked context before route render completes.
11. Avoid MutationObserver complexity.
12. Avoid a global event bus when direct imports suffice.
13. Keep the shell API idempotent.
14. Permit context updates after asynchronous destination resolution.
15. Ensure replaced actions remove obsolete listeners by using anchors only.
16. Make parent navigation the first interactive item.
17. Preserve modifier-click and open-in-new-tab.
18. Keep route adapters responsible only for mapping config to the shared model.
19. Add a Create adapter without rewriting its large behavior module.
20. Verify source line ceilings after every write.
21. Verify leading-space indentation in touched JavaScript and CSS.
22. Test missing-context labels for all specialist routes.
23. Test that no specialist route appears in the visible command results.
24. Add forced-colors support to the ribbon.
25. Make mobile metadata wrap instead of horizontally scroll.
26. Keep the dock safe-area offset independent from ribbon height.
27. Avoid sticky ribbon behavior until occlusion is measured.
28. Use semantic tokens already present instead of inventing a competing palette.
29. Record any runtime uncertainty rather than claiming completion.
30. Re-read every touched file before final reporting.
