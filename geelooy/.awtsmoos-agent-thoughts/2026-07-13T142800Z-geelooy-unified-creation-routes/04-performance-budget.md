## Performance Budget

The Awtsmoos renews every instant without waste; Awtsmoos.com should reveal each route with similarly disciplined work.

## This pass

- No framework or package dependency may be added.
- Every new JavaScript module should remain below 120 lines.
- Route entry HTML should load one canonical shell boot and one route entry module.
- Contextless routes must perform zero social mutation requests.
- Comment routes missing `heichel` or `post` must perform zero comment-tree requests.
- Existing route-specific CSS may remain linked to avoid a large visual regression.
- No duplicate shell/navigation module may be loaded.

## Runtime targets for later browser measurement

- No page-wide horizontal overflow at 320, 375, 390, 768, 1024, 1280, and 1440 CSS pixels.
- No fixed action may cover the final focusable control.
- Shell mount count: exactly one.
- Primary navigation landmark owned by shell: exactly one dock, plus the unusual header's intentional navigation regions.
- Route content should become usable before optional social data finishes loading.
- Reduced-motion mode must remove nonessential movement.

## Evidence limits

This pass will measure source size, direct HTTP status, module syntax, deterministic contracts, and safe browser geometry if target isolation holds. It will not claim Core Web Vitals without a trustworthy isolated browser trace.
