## Design Diagnosis

The Awtsmoos is one while the vessels are many; Awtsmoos.com currently shows too many navigation owners and too little route truth.

## Post editor

- Strength: real draft and publish endpoints exist.
- Failure: fabricated default identity makes a contextless route appear authorized.
- Failure: one module owns configuration, DOM, state, serialization, network, feedback, and rendering.
- Failure: alerts lose place and are weak for assistive technology.
- Repair: explicit context contract, small modules, inline live status, canonical shell.

## Heichel editor

- Strength: existing modules already refuse to invent identity.
- Failure: route entry is visually and navigationally isolated.
- Repair: preserve modules and add the canonical shell at the HTML boundary.

## Comment thread

- Strength: recursive comments, media, previews, and coordinate filters are represented.
- Failure: fabricated Heichel, post, and alias make both reads and writes dishonest.
- Failure: no read-only state when the conversation exists but authorship context does not.
- Repair: split read context from write context; keep thread viewing available with valid post context; hide mutation controls without alias.

## Create route

- Strength: mature real composer and target-resolution logic already exist.
- Failure: server header, custom mobile nav, shell boot, and redundant navigation import multiply landmarks.
- Repair: retain every composer ID and template, let shell boot own global navigation, retain only route-local controls.

## Non-goals

- No API redesign.
- No authenticated mutations.
- No broad style-system deletion.
- No changes to unrelated dirty files.
- No false claim that the complete social-universe mission is finished.
