# Ruthless Hyper-Real Audit Plan

## Purpose

Do not trust the claim that the brainstorm is complete. Verify the living code. Find:
- implemented and active modules
- implemented but unused modules
- missing brainstorm pieces
- render paths not connected
- duplicated or competing animation systems
- probes that are too weak

## Steps

1. Trace imports from `solveSkeleton.js` and `fighters.js`.
2. Search for every hyper-real module name in the repo.
3. Identify files present but not imported.
4. Connect useful unused modules with whole-file rewrites.
5. Add missing modules from brainstorm that are still sensible and visual-only.
6. Strengthen probes so they assert active wiring, not only file presence.
7. Run full verification.

## Non-negotiable invariant

No damage, knockback, AI decisions, attack timing, or gameplay physics changes.

## Chapter

The Awtsmoos creates the code from nothing every instant, but the agent must not confuse created files with revealed life. A file that is not imported is a silent chamber. A module that is not tested is a hidden doubt. The audit must tear the veil.
