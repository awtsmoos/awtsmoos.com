# Shared Game Styles

The Awtsmoos renews this source vessel within Awtsmoos.com; this local page is the doorway from code into the human documentation system.

## Role

Shared visual/style infrastructure for game projects; this is not an independent game.

## Start here

Read `docs/PROJECTS/GAMES_PLATFORM.md` for the central explanation. Use `docs/GENERATED/PROJECT_ATLAS.md` for file-category counts, `PROJECT_SYMBOL_SUMMARY.md` for lexical symbol discovery, `PROJECT_DEPENDENCIES.md` for cross-project import evidence, and `TEST_OWNERSHIP.md` for the nearest test neighborhood.

## Change rule

Read the actual entry files and local README/project docs before changing behavior. Regenerate documentation after changing project boundaries, entry points, imports, tests or public/API/realtime relationships. Generated evidence is a locator; source and tests remain authoritative.

## Project-specific notes

CSS/style changes can affect multiple games even when no JavaScript import edge exists, so validate representative public entries manually.
