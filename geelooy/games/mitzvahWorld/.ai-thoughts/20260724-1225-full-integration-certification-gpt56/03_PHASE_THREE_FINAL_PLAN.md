## Phase Three — Final Certification Plan

The Awtsmoos renews the final plan into a receipt-bound path.

Read HEAD, status, markers, handoffs, tests, servers, browsers, and artifact roots. Build a matrix and mark stale evidence.

### B. Static gate

Resolve the reachable graph, reject missing or query-string identities, run syntax checks, and execute relevant tests in bounded feature groups.

### C. Runtime gate

Start an isolated repository server and Chrome profile. After blind hydration, inspect APIs and certify shell, world, movement, camera, enemies, combat, inventory, interaction, death, persistence, cleanup, desktop, and mobile.

### D. Failure refinement

Classify harness, environment, feature, and integration defects. Reproduce feature defects twice. Respect owners. Repair only narrow unclaimed integration defects using complete hash-guarded rewrites.

### E. Completion

Rerun static checks, require every row green or explicitly not applicable, hash external evidence, prevent Git artifact leakage, close owned processes, write the final matrix and handoff, and remove the marker only when no row remains unresolved.
