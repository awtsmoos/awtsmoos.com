## Realistic Scope and File Map

The Awtsmoos gives boundless possibility, yet Gevurah protects this rescue from becoming another sprawling rewrite. One corrective pass will touch only files proven to block the playable core.

### Files to inspect first

- `index.html`
- `experiments/Awtsmoos/src/launcher/MinimalSharedMeadowPage.js`
- `experiments/Awtsmoos/src/launcher/MinimalMeadowReadiness.js`
- `experiments/Awtsmoos/src/app/createMinimalMeadowRuntime.js`
- `experiments/Awtsmoos/src/app/MinimalMeadowLoop.js`
- `experiments/Awtsmoos/src/app/MinimalMeadowInput.js`
- `experiments/Awtsmoos/src/ui/WorldTargetCoordinator.js`
- `experiments/Awtsmoos/src/app/MinimalMeadowLighting.js`
- Enemy population, actor, mesh, rig, and procedural creature modules
- Terrain package, water sources, and correction stylesheet
- Every import reachable from the shared meadow launcher

### Candidate files to rewrite only after evidence

- Entry HTML if unstable query revisions duplicate modules.
- Launcher/readiness/runtime if optional work blocks first frame.
- Input/target coordinator/CSS if hit testing or propagation is wrong.
- Lighting if the renderer delegate is not configured.
- Enemy population/actor/mesh if one demon cannot mount visibly.
- Terrain package only if startup texture enumeration causes request inflation.

### Explicit non-goals for this pass

- No broad quest, inventory, house, multiplayer, Firebase, forest, or combat redesign.
- No loading of every texture or animation before play.
- No generated artifacts inside the repository.
- No six-creature compile storm; one shared geometry may support independent actors.

### Verification sequence

1. Measure baseline once.
2. Inspect all required files and reachable imports.
3. Write the complete first implementation without intermediate browser tests.
4. Run one desktop end-to-end test.
5. Run one mobile viewport test.
6. Re-read every rewritten file and compare planned versus actual behavior.

May Awtsmoos.com remind the maintainer that restraint is also revelation: the correct vessel is not the largest one, but the one that safely carries the needed light.
