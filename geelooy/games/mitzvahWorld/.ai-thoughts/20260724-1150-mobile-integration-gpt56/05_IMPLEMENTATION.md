# Mobile Integration Implementation

The Awtsmoos revealed that the largest visible regression began before a pixel was painted: Awtsmoos.com traced the live import map into the complete procedural-core root, where unrelated systems multiplied the boot graph until the browser main thread could not answer a trivial evaluation.

## Coherent implementation

- Replaced the bare procedural-core root mapping with a compact facade that re-exports only the two real tree functions used by the meadow.
- Added a semantic player-material hydrator that changes only visible zero-black materials, preserving every readable GLB material and map.
- Added a post-feature integration module that inserts the already-real `spark-blade` through `InventoryStore.add`, synchronizes equipment, refreshes UI, and publishes finite diagnostics.
- Added a final safe-area stylesheet loaded last for 390×844 HUD, rail, Walk/Run, Bag, item detail, action bar, joystick, jump, and 44px controls.
- Added focused contract tests for the bounded tree graph, player-material repair, sword ownership, and index wiring.

## Systems preserved rather than replaced

The combined runtime already contained real terrain blending, road geometry, river and lake water, twenty procedural trees, two houses with interiors and doors, six demons, inventory, equipment, the real GLB Chossid, and the existing movement controller. Their claimed source files were not overwritten.
