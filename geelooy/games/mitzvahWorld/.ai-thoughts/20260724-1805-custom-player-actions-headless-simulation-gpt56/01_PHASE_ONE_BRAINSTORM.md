# Phase One: Possibility Map

The safest architecture is a declarative registry above an actor-neutral runtime. Imported GLB clips continue beneath it. Custom definitions contain semantic bone roles, keyframes, equipment requirements, release events, and interruption policy. A message bridge translates real combat lifecycle events into distinct staff or sword messages and also accepts future registered AI messages.

The simulation must not fork gameplay rules. It should reuse the real event bus, inventory, combat coordinator, movement controller, octree, capsule mover, and triangle colliders. Only DOM, renderer, and WebGL are replaced with deterministic vessels. The GLB loader reads the real binary JSON chunk, so animation and skeleton inspection remain grounded in the shipped asset.

Friendly NPCs should load the same canonical GLB URL through the existing isolated loader. Each NPC receives its own scene/skeleton instance, imported animation player, and custom-action runtime; shared source identity does not mean shared mutable bones.
