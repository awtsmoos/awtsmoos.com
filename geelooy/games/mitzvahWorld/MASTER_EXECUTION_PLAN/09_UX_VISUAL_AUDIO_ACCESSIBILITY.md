# 09 — UX, Visual Art Direction, Audio, Accessibility

## Reference-image target
The desired feel is cinematic realism with restrained black/gold/contextual UI: mountain valleys, rivers/waterfalls, village streets, forests, Beis Midrash interiors, coast/desert/night, Creator placement, traversal challenges, community events. Improve on the images by making every scene systemic and playable.

## HUD / interaction
- [ ] contextual HUD; do not permanently cover scenery with panels;
- [ ] quest panel collapses; map/bag/quest controls reveal contextually;
- [ ] semantic minimap from actual roads/rivers/elevation/landmarks/discovery;
- [ ] full map from generated geography, not a disconnected decorative image;
- [ ] landmark-based navigation and real NPC directions;
- [ ] quiet exploration mode with minimal UI;
- [ ] Creator UI usable on phone, tablet, desktop; landscape/portrait layouts recompose rather than scale blindly;
- [ ] safe-area handling and touch targets for modern phones.

## Visual quality
- [ ] atmosphere depth: haze, layered mountains, cloud shadows, sunlight transmission, sunrise/golden-hour exposure;
- [ ] water: reflection, foam, rapids, shallow/deep variation, waterfall spray and hydrologic continuity;
- [ ] terrain material transitions invisible at normal view distance;
- [ ] vegetation silhouettes varied; forest floor matches canopy ecology;
- [ ] temporal stability: no shimmering foliage/grass/terrain at distance;
- [ ] shadow budget by semantic importance; hero contact shadows only where affordable;
- [ ] dynamic exposure restrained—no brightness pumping or crushed player silhouette;
- [ ] night lighting from real local sources/moon/sky, not globally bright darkness.

## Cinematic / shareable polish
- [ ] scenic composition scoring, vista preservation, landmark framing;
- [ ] photo mode with time/weather controls where appropriate;
- [ ] deterministic showcase camera points and automated reference screenshots;
- [ ] guided tours/highlights generated from real world locations/events, not fake footage.
## Audio
- [ ] spatial ambience derives from actual environment/activity: forest, waterfall, village, study hall, coast, night, desert;
- [ ] rain material response differs on leaves, roofs, dirt, stone, water;
- [ ] thunder distance/occlusion/reverb, interior muffling, valley echoes;
- [ ] wind sound varies by vegetation species/canopy density;
- [ ] snow damps high-frequency ambience;
- [ ] civilization ambience reflects real NPC density/work/events rather than fixed loops;
- [ ] audio LOD/culling/voice budgets prevent crowd/weather scenes from exhausting the device;
- [ ] music supports rather than continuously overwhelms natural sound.

## Accessibility / controls
- [ ] text scaling, high contrast, subtitles/captions, readable quest/map typography;
- [ ] Hebrew/RTL layout correctness and consistent terminology;
- [ ] reduce motion/camera shake; never require violent camera effects;
- [ ] reduced lightning flash/photophobia-safe weather mode;
- [ ] remappable keyboard/gamepad; customizable touch layout;
- [ ] color/contrast remains usable under fog/night/storm/snow;
- [ ] important gameplay markers remain perceivable without destroying atmosphere;
- [ ] no mandatory sound-only or color-only critical information.

## First 60 seconds
- [ ] world visible quickly;
- [ ] movement obvious and responsive;
- [ ] no developer/debug garbage;
- [ ] stable frame pacing;
- [ ] nearby interesting affordance without overwhelming tutorial text;
- [ ] loading stages say meaningful things (`Preparing terrain`, `Entering world`, `Bringing nearby life online`) rather than fake percentages;
- [ ] no unexplained long spinner.

## Art/content review
- [ ] important Jewish architecture/signage/objects receive human review;
- [ ] no accidental crosses/other religious motifs;
- [ ] Hebrew text checked for correctness and direction;
- [ ] Rambam menorah depiction uses straight branches when relevant;
- [ ] visual beauty never substitutes for functionality: doors open, bridges collide, water connects, NPCs have real behavior.
