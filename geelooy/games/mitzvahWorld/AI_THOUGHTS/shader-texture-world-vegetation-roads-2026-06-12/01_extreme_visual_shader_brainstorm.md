# Phase One — Extreme Shader / Vegetation / Flower / Rock / Yellow Brick / Lampshade Brainstorm

User asks: brainstorm heavily how to improve generation of every shader fully; inside looks of vegetation flowers and rocks and place them throughout the level; yellow brick roads; lamp shades; every extreme feature of WebGL to use for generation; improved.

Immediate visual reading from screenshot:
- Preview PNGs look correct as a proof of output, but still too simple/blurred/patterned for full realism.
- Burlap lacks visible woven fiber separation and frayed thread detail.
- Roof tiles are readable but too regular and toy-like; need chipped edges, moss, varied tile color, shadowed overlap.
- AO/height maps are useful, but patterns need stronger material-specific masks.

Extreme shader material upgrade brainstorm by category:

A. General WebGL/procedural texture generation features
1. True tileable noise using torus coordinates: sample noise on sin/cos uv embedding to remove seams.
2. Domain warping with multiple independent vector fields.
3. Ridged multifractal noise for cracks and bark grooves.
4. Cellular/Voronoi with edge distance for stones, pebbles, scales, petals.
5. Worley F1/F2 difference for crack networks.
6. Signed distance fields for tile/mortar/brick masks.
7. Procedural bevel/edge highlights from distance fields.
8. Curvature-like AO from height second derivatives.
9. Normal map from Sobel filter over height field.
10. Multi-channel PBR packing: roughness, AO, metallic/unused in one packed texture.
11. Palette ramps per material with physically plausible color ranges.
12. Micro-detail overlay from high frequency blue-noise-ish hash.
13. Macro stains from low frequency masks.
14. Per-cell random hue/saturation for stones/roof tiles.
15. Crack masks generated by warped sine ridges plus Voronoi edges.
16. Dirt accumulation based on height valleys and AO.
17. Wetness masks for mud/stone lower roughness.
18. Optional parallax height if material later uses custom shader.
19. Mip-aware procedural preview: generate 512, let Three mipmap.
20. Texture atlas generation in RAM for repeated props.
21. Object-space triplanar shader for terrain/rocks instead of UV stretching.
22. Baked procedural decals for path edges and footprints.
23. Procedural derivative anti-aliasing if real fragment shader is used.
24. WebGL2 render-to-texture path later: GLSL fragment shader, framebuffer, readPixels or direct texture use.
25. Worker-safe CPU fallback already done; can mirror GLSL formulas.
