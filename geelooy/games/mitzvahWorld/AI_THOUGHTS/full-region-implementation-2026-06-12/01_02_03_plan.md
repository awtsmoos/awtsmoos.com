# Three Phase Plan — Full Region Stack Implementation Pass

## Phase 1 brainstorm
The request says write every theoretical file. The only safe way is to implement a complete first functional region stack with all planned modules present, small, composable, and wired through postbuild. This cannot become a AAA wildlife simulator in one pass, but it can become a real architecture that creates visible region layers, wildlife markers, instancing pools, roads, biomes, houses plans, collider classification, and debug reporting.

## Phase 2 concrete target
Create all planned directories/files with full contents. Keep files small. Use shared data. Wire `MitzvahRegionDirector` into `MitzvahWorldPostBuild`. Avoid destructive edits. Keep visual-only layers out of octree. Add merged collider builder as conservative reporting/geometry factory, not aggressive octree mutation unless API is known. Use existing terrain grounding and material systems.

Write region modules:
- region director/seed/phases
- terrain recipes/valley/water
- instances pool + grass/flower/rock/tree layer specs
- trees catalog/genome/mesh factory/forest/orchard
- roads network/yellow brick/animal trails/wear
- biomes village/farm/orchard/forest/marsh/highlands
- farms wheat/vegetables
- wildlife director/species/territories/needs/predator scheduler
- npc schedule/route/professions
- houses planner/professions/interiors
- collision classifier/grounded builder/merged bake/report
- debug reports
- library helper files in geelooy/libs
Then wire postbuild.
