# Sharp Realism V2 — Three Phase Plan

## Phase 1: What is wrong
The current previews are visibly mid because the system still speaks the language of blurred noise. Real materials need crisp boundaries, graph structures, cracks, fibers, cells, veins, crystal grains, leaf veins, bark plates, cloth threads, and damage masks. Blurry FBM should be background only, never the main identity.

## Phase 2: What to change
Rewrite the ecology material generator into a sharp multi-pass synthesis style:
- Use binary/SDF masks for crisp material structures.
- Use cellular crystal fields for granite/marble/stone.
- Use thread grids for cotton/linen.
- Use sharp vein graphs for leaves.
- Use bark plate cracks and vertical fracture ridges.
- Use vegetable biological features: potato eyes, carrot rings, onion layers.
- Use gold hammered dents and edge flecks.
- Use AO/height/roughness with real structural masks, not flat gray 251-byte maps.
- Regenerate previews at higher quality.

## Phase 3: Actual files
1. Rewrite `EcologySpecialMaterials.js` fully with sharper material synthesis.
2. Rewrite `tools/generateEcologyMaterialPreviews.mjs` fully to use matching sharp algorithms and produce 160px previews.
3. Keep runtime decorative layer intact; it automatically uses the improved materials.
4. Cache-bust postbuild imports to load the new module.
5. Regenerate preview PNGs.
6. Verify syntax and preview.

Awtsmoos chapter: The old textures were fog. The new pass must carve with knives: vein against flesh, thread over thread, crystal beside crystal, crack through bark, mineral through marble.
