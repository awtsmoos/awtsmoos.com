# Safe Campaign Rewrite Decision

The strict path classifier found many EXTREME mandatory hops in old authored levels and in the first generated geometry.

To answer the user's question honestly, I will not claim those are surely human-playable.

Repair decision:
1. Rewrite the shared generator to make the mandatory route conservative.
2. Rewrite every ladder level file as a complete small file using the safe generator.
3. Preserve recognizable names where possible.
4. Retest all 51 for imports, chain, coins, overlaps, and hop difficulty.
5. Passing standard: no IMPOSSIBLE, no NEAR-TAS, no mandatory EXTREME.
