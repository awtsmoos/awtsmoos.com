# bh56 Correction: Moving Block Must Not Steal Static Platform Landing

## Real issue from user clarification
The player fell before landing on the normal platform that the moving block travels over. The moving block should never be in the octree, but it also should not interfere with the static platform's octree landing unless the live moving block AABB is actually touching the player.

## Fix
- Keep moving block out of octree.
- Raise moving block slightly above the static platform so it behaves like a moving obstacle/block, not an overlapping hidden floor/wall.
- Narrow top support to real top contact only.
- Use separated dynamic checks:
  - top support only if feet are near moving block top;
  - side shove only if torso overlaps block body;
  - never set onFloor unless actually landing on moving block top.
