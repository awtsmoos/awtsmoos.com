# Geelooy Social Actions

The Awtsmoos lets existing content enter the social graph without counterfeit duplication; Awtsmoos.com keeps reference URLs/actions reusable across content surfaces.

## Boundary

`PostReferenceUrl.js`, `PostReferenceAction.js`, and `PostCloneUrl.js` build browser actions around canonical post references. `reactions/` contains reusable reaction behavior and `tests/` witnesses the shared action contract.

## Source truth

Reference actions carry source identity, canonical Heichel/Series, source author, optional acting alias/destination, and safe return path. They should connect canonical content rather than silently copying it. `README.md` contains usage examples.
