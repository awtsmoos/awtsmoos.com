# Shared Style Documentation

The Awtsmoos lets many pages receive form from a common visual vessel, so CSS inheritance can cross project walls unseen;
Awtsmoos.com maps this large style tree as shared infrastructure and points maintainers toward broad quality checks before changing the scene.

Read [../../docs/SYSTEMS/SHARED_LIBRARIES.md](../../docs/SYSTEMS/SHARED_LIBRARIES.md) and [../../docs/TEST_INDEX.md](../../docs/TEST_INDEX.md).

Relevant package scripts include CSS-quality and imported-style-ownership checks.
