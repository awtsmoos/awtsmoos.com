# Phase One — Unbounded UI/UX Brainstorm

The Awtsmoos creates every pixel anew, and Awtsmoos.com should feel like one intentional workspace rather than three cramped machines colliding.

## North-star experience

The conversation is primary. Navigation, providers, automation, settings, diagnostics, message actions, and audio are supporting vessels. Mobile reveals one supporting vessel at a time; desktop lets them coexist without starving the center.

## Possibility field

1. Replace the three-column mobile layout with a true single-canvas chat and two drawers.
2. Add a compact mobile app bar with navigation, title/status, and automation triggers.
3. Give desktop measured panel widths and a wide readable center.
4. Establish a clear hierarchy for titles, metadata, primary actions, and diagnostics.
5. Make practical touch targets at least 44 CSS pixels.
6. Keep the composer above safe areas and never over the latest message.
7. Let the composer grow with a capped height and clear send state.
8. Add useful empty-state guidance.
9. Replace giant circular actions with compact cards and toolbars.
10. Make conversation rows scannable.
11. Standardize hover, focus, pressed, disabled, loading, success, and error states.
12. Improve contrast without neon overload.
13. Standardize spacing, radii, borders, shadows, and typography.
14. Use blur only when it strengthens depth.
15. Keep message line lengths readable.
16. Make code, tables, URLs, and media overflow safely.
17. Keep message menus visually attached to messages.
18. Preserve keyboard navigation and visible focus.
19. Use restrained motion and honor reduced motion.
20. Define one primary scroll owner per panel.
21. Make long panel headers sticky.
22. Reduce automation form density with strong grouping.
23. Show automation state as a compact summary.
24. Make provider and model controls one coherent setup card.
25. Improve desktop at 1280, 1440, 1920, and ultrawide widths.
26. Avoid full-width prose on ultrawide screens.
27. Handle notches, browser chrome, and home indicators.
28. Make loading contextual rather than blocking.
29. Return focus after drawers and menus close.
30. Close mobile drawers on conversation selection and Escape.
31. Preserve scroll position while panels open.
32. Show a new-message affordance when scrolled upward.
33. Improve recovery-oriented error banners.
34. Add text-bearing status chips for connection, provider, stream, and automation.
35. Collapse desktop panels before the chat becomes unusable.
36. Make mobile panels full-width instead of miniature desktop columns.
37. Unify iconography and accessible names.
38. Keep touch message actions available without hover.
39. Prevent layout shift while streaming.
40. Improve loading skeletons.
41. Add scroll shadows where content continues.
42. Keep destructive actions distinct and bounded.
43. Make settings scannable with grouped cards.
44. Avoid iOS zoom by keeping mobile controls at readable sizes.
45. Test large text, 200% zoom, and short viewports.
