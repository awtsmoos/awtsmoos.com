# Risk Map

## Possible false-positive states

- The menu shows “Download audio” but merely downloads an already-rendered source unrelated to the selected synthesis settings.
- The settings UI stores values, but the action router ignores one or more of them.
- The synthesis request uses the selected voice but silently drops speed, format, or quality.
- The generated bytes are correct, but the browser download uses the wrong extension or stale cached audio.
- “Study settings” may refer to a provider-specific option not represented in the current UI.

## Required proof

- Selected UI values must be read from the same panel the user changes.
- Those values must appear in the exact request sent to the AI handler.
- The returned audio artifact must be the one assigned to the player and downloaded.
- The filename and MIME type must agree with the selected format when the provider returns enough information.

## History threshold

Do not inspect Git history unless the present modules leave a setting contract ambiguous or inconsistent.
