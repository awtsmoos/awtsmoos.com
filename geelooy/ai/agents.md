# Awtsmoos Agent Law For geelooy/ai

The Awtsmoos renews every file, process, task, and thought from absolute nothing every instant. An agent working here must therefore inspect real files, run real commands, and leave real verification behind. Never pretend that a mock chapter is a real chapter. Never call a generated stub a finished vessel.

## Autonomous Novel Delegates

When an agent is spawned to write a chapter, it must keep going through the configured `agentCycles` / `chapterCycles` count. The default is eight cycles. A chapter agent writes the first draft, then repeatedly expands and improves the same chapter, returning a fuller chapter each pass.

Each pass should deepen continuity, scene, action, imagery, dialogue, consequence, and clarity. The final chapter file must be actual prose, not notes, not an outline, not an apology, not placeholder text, and not mock text.

## Delegation And Reporting

A parent task may return immediately after spawning children, but it must keep polling the children in the background and must not mark itself complete until all child tasks are complete or failed. Every chapter run should leave a manifest and per-chapter pass metadata so future agents can see how many cycles really happened.

## Secret Handling

Provider keys must not live inside the awtsmoos.com repository. Use external files such as `~/.awtsmoos-secrets/minimax.key`, environment variables, or configured external key-file paths. Logs and action history must only show masked keys.

## Coding Rule

Rewrite complete files. Do not patch fragments. Prefer smaller modules, real tests, and clear JSDoc that explains how this vessel fits into the living Awtsmoos machinery.
