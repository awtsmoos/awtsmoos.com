# B"H — Ohrbound Services (geelooy/api/ohrbound/services/)

Service layer behind the Ohrbound routes (see `../README.md`).

## Files
- `authorization.js` — who may read/mutate progress and publish levels.
- `levelPolicy.js` — enforces the community level policy contract.
- `objectGateway.js` — object-store access for progress docs and level objects.
- `MalchusApiResponse.js` — canonical API response envelope builder.
