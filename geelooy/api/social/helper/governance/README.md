# B"H — Governance (geelooy/api/social/helper/governance/)

Legacy governance helpers: Heichel settings, roles, invites, and submissions.

## Files
- `heichelSettings.js` — Heichel governance settings.
- `roles.js` — role definitions (owner, editor, moderator, contributor).
- `invites.js` — invitation handling.
- `submissions.js` — governance submissions.

The newer, unified implementation lives in `unifiedSocial/` (permissions, review); these are the legacy counterparts still in use.
