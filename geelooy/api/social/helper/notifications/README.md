# B"H — Notifications (geelooy/api/social/helper/notifications/)

Notification domain model: types, storage, mutations, queries, preferences, and mirroring.

## Files
- `NotificationModel.js`, `NotificationTypes.js` — model and notification types.
- `NotificationMutations.js`, `NotificationQueries.js` — write/read operations.
- `NotificationPreferences.js` — per-user preferences.
- `NotificationMirror.js` — mirrors notifications to other stores/surfaces.
