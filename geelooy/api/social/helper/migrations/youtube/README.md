# B"H — YouTube Migration (geelooy/api/social/helper/migrations/youtube/)

Importer for migrating YouTube content (captions, manifests) into Awtsmoos.

## Files
- `YouTubeManifest.js`, `ManifestGuard.js` — migration manifest and validation guard.
- `YouTubeCaptionAssets.js` — caption asset handling.
- `YouTubeMigrationPlan.js`, `YouTubeMigrationRoutes.js` — migration planning and HTTP routes.
- `SourceProvenance.js` — provenance tracking.
- `test/` — `ManifestGuard.test.js`, `YouTubeManifest.test.js`.
