# B"H — Migrations (geelooy/api/social/helper/migrations/)

External-platform migration importers: Meta assets/content and YouTube captions/manifests.

## Subdirectories
- `meta/` — Meta migration: manifest + guards, content kinds, plan, routes, diagnostics, capabilities, source provenance, secret-field guarding.
- `youtube/` — YouTube migration: caption assets, manifest + guard, migration plan/routes, source provenance, plus `test/`.
- `ArchiveOrgPublicAsset.js` — archive.org public-asset migration helper.
