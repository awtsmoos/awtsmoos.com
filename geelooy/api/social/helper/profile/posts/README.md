# B"H — Profile Posts (geelooy/api/social/helper/profile/posts/)

Post collection and projection for profiles: gather posts across series/Heichelos and project them into profile views.

## Files
- `PostCollector.js` — collects posts for an alias.
- `PostCoordinates.js` — locates posts (heichel/series/post coordinates).
- `PostProjection.js` — projects post records into profile-view shape.
- `PostsByAlias.js` — posts grouped by alias.
- `test/` — `PostProjectionTruth.test.js`.
