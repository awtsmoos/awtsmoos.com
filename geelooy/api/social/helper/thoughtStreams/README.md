# B"H — Thought Streams (geelooy/api/social/helper/thoughtStreams/)

"Thought streams": short-form posts (thoughts) with reads, writes, reactions, queries, and sanitization. Mounted via `_awtsmoos.thoughts.js`.

## Files
- `write.js`, `read.js`, `query.js` — write, read, query streams.
- `reactions.js` — stream reactions.
- `sanitize.js` — input sanitization.
- `paths.js` — storage paths.
