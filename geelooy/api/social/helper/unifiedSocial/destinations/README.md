# B"H — Unified Social Destinations (geelooy/api/social/helper/unifiedSocial/destinations/)

Destinations for unified publishing: where content may be placed (Heichels, series), with evidence, policy, and management routes.

## Files
- `DestinationService.js`, `DestinationSchema.js`, `DestinationRouteHandlers.js` — service, schema, routes.
- `HeichelEvidence.js` — Heichel evidence for destination policy.
- `InlineCreationService.js` — inline Heichel/series creation.
- `ManagementRoutes.js` — destination management routes.
- `SeriesTree.js` — bounded nested-series traversal.
