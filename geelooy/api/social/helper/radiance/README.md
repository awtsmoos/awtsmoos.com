# B"H — Radiance (geelooy/api/social/helper/radiance/)

"Radiance" quality/ranking signal for social discovery: scores and ranks content so the best rises.

## Files
- `index.js` — module entry.
- `RadianceScorer.js` — computes radiance scores.
- `RadianceSignal.js` — signal inputs to scoring.
- `RadianceWeights.js` — scoring weights.
- `RadianceRanker.js` — ranks content by radiance.
- `test/` — `radianceDiscovery.test.js`.

Mounted via `_awtsmoos.radiance.js`.
