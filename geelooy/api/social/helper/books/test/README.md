# B"H — Books Tests (geelooy/api/social/helper/books/test/)

Tests for the print-book builder.

- `bookRender.test.js` — book/chapter/front-matter rendering.
- `bookRoutes.test.js`, `bookDirectRoute.test.js` — book HTTP routes.
- `bookTree.test.js` — series-tree assembly.
- `bookZip.test.js` — zip packaging.
- `bookResilience.test.js` — job/worker resilience.
- `bookUnicodeDownload.test.js` — unicode filename/download handling.
- `runAll.js` — runs the whole book suite.
