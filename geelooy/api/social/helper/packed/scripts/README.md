# B"H — Packed Migration Scripts (geelooy/api/social/helper/packed/scripts/)

One-off migration scripts that move packed social data into real AwtsmoosDB (run manually).

- `migrateConnectedPostsToAwtsdb.js` — connected posts → AwtsmoosDB.
- `migrateHeichelFamiliesToRealAwtsmoosDbFs.js` — Heichel families → AwtsmoosDB FS.
- `migrateHeichelToRealAwtsmoosDbFs.js` — Heichel data → AwtsmoosDB FS.
- `migrateIkarAllSeriesToAllPosts.js` — all Ikar series → all-posts index.
- `migrateIkarPostsToRealAwtsmoosDb.js` — Ikar posts → AwtsmoosDB.
