# B"H — Ayin Beis Importer (geelooy/api/social/helper/imports/ayinBeis/)

Bulk import pipeline for the Ayin Beis corpus.

## Files
- `index.js` — module entry.
- `importPlanner.js` — plans what to import and where it lands.
- `importWriter.js` — writes imported content into the social store.
- `authorizedBundle.js` — authorized import bundle handling.
- `test/` — `authorizedBundle.test.js`, `importPlanner.test.js`, `importWriter.test.js`.
