# B"H — Entity Universe (geelooy/api/social/helper/entityUniverse/)

The "universe" store for entities: schema, DNA, paths, and persistence for the entity universe graph.

## Files
- `universeSchema.js`, `universeDna.js` — universe schema and entity DNA definitions.
- `universePaths.js` — storage paths.
- `universeStore.js` — read/write store.
- `rangeReferences.js` — range-based references between entities.
- `test/` — store and stress-network tests (`universeStore.test.mjs`, `universeStressNetwork.test.mjs`).
