# B"H — Objects (geelooy/api/social/helper/objects/)

Object registry for social objects: schema, store, search, relationships, timeline, cards, health, and metrics. Mounted via `_awtsmoos.objects.js`.

## Files
- `index.js` — module entry; `registry.js` — object registry.
- `schema.js`, `store.js` — object schema and store.
- `search.js`, `relationships.js`, `timeline.js` — search, relations, timeline views.
- `cards.js`, `inspector.js` — card rendering and object inspection.
- `health.js`, `metrics.js` — health checks and metrics.
- `adapters.js` — storage/source adapters.
