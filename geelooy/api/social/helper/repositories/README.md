# B"H — Repositories (geelooy/api/social/helper/repositories/)

Git repository hosting over HTTP: clone service, CGI gateway, auth, credentials, policy, and a virtual OS tree view.

## Files
- `gitCloneService.js`, `gitHttpGateway.js`, `gitCgiResponse.js`, `gitProcess.js` — git-over-HTTP serving.
- `gitBasicAuth.js`, `gitRemotePolicy.js` — auth and remote policy.
- `repositoryStore.js`, `repositoryPaths.js`, `repositoryPolicy.js`, `repositoryAuthorization.js` — repo storage, paths, policy, authorization.
- `repositoryCredentialCrypto.js`, `repositoryCredentialService.js` — credential handling.
- `virtualOsTree.js` — virtual OS tree view of repositories.
