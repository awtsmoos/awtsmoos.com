# B"H — Social Kernel Capabilities (geelooy/api/social/helper/socialKernel/capabilities/)

Capability system for the social kernel: what an actor may do, compiled into a catalog and enforced by policy.

## Files
- `SocialCapabilityCatalog.js` — catalog of capabilities.
- `SocialCapabilityPolicy.js` — policy deciding which capabilities apply.
- `SocialAnswerCapability.js`, `SocialAuthorityCapability.js`, `SocialFollowCapability.js` — answer/authority/follow capabilities.
