# B"H — Comment Migration Scripts (geelooy/api/social/helper/comments/scripts/)

One-off migration scripts for the comment system (run manually, not part of request handling).

- `copyLegacyCommentsToNewSystem.js` — copies legacy comments into the new comment system.
- `migrateOldCommentsToAwtsmoosDb.js` — migrates old comments into AwtsmoosDB storage.
