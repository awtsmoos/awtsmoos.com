# B"H — Imported Comment Adapters (geelooy/api/social/helper/comments/imported/adapters/)

Source adapters that let the imported-comment orchestrator read from different storage backends.

- `bundleAdapter.js` — reads imported comments from bundles.
- `corpusAdapter.js` — reads from raw corpus data (`data/`).
- `legacyAdapter.js` — reads legacy comment stores.
- `shardAdapter.js` — reads sharded AwtsmoosDB comment storage.
