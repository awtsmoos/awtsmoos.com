# B"H — Sichos Kodesh Imported Posts (geelooy/api/social/helper/comments/imported/data/sichosKodesh/)

The Sichos Kodesh imported corpus data.

- `manifest.json` — index of the corpus.
- `posts/` — 283 JSON files, one per imported post (hash-named).

Consumed by the imported-comment adapters and post resolver to serve imported comment trees through the normal comment routes.
