# B"H — Comment Translations (geelooy/api/social/helper/comments/translations/)

Translation bundles for comments: cataloging, storing, reading, searching translations, and measuring coverage.

## Files
- `catalog.js` — translation bundle catalog.
- `corpusStore.js` — storage of translation corpora.
- `reader.js` — reads translations for comments.
- `search.js` — searches within translations.
- `coverage.js` — measures translation coverage per series/post.

Serves the `.../translations`, `.../translations/coverage`, and `.../translations/search` routes.
