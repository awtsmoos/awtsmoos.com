# B"H — Nav Utilities (geelooy/api/nav/)

Client-side navigation helper, not an HTTP route family (no `_awtsmoos.derech.js`).

## Files
- `highlighter.js` — `ParagraphHighlighter`: highlights the currently-in-view
  paragraph inside a container, with highlight/deselect callbacks and an option
  to disable deselection. Used by reader-style navigation UI.
