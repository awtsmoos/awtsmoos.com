# B"H — YouTube Docs (geelooy/api/youtube/docs/)

Single guide: `SETUP.md` — Awtsmoos YouTube integration setup. Covers the
public manager at `/youtube/`, Google Cloud configuration (enable YouTube
Data API v3, create a Web OAuth client with redirect URI
`https://awtsmoos.com/api/youtube/oauth/callback`), the incremental OAuth
permission modes (read / upload / manage), and how to install the OAuth JSON
secret without it ever entering Git.
