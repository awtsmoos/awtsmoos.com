# B"H — Builder Templates (geelooy/api/wallet/core/commerce/builderTemplates/)

Commerce data for app-builder templates sold/purchased through the wallet.

Files:
- `catalog.js` — builder template catalog (what's purchasable)
- `markup.js`, `script.js`, `style.js` — template content assets

Backed by `commerce/builderTemplate{Access,Delivery,Skus}.js`; covered by
`tests/builderTemplateCommerce.test.js`.
