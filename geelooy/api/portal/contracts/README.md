# B"H — Portal Contracts (geelooy/api/portal/contracts/)

The declarative contract vocabulary of the Portal API (see `../README.md`).

## Files
- `PortalResourceEnvelope.js` — the canonical response envelope.
- `PortalTypeDefinition.js` / `PortalTransformation.js` / `PortalRelationship.js`
  — type shapes, transforms, and relations.
- `PortalQueryDefinition.js` / `PortalActionDefinition.js` / `PortalJob.js`
  — queries, actions, and async jobs.
- `PortalContractPrimitives.js` / `PortalContractLimits.js` — primitives and bounds.
- `PortalErrorResource.js` — error resource shape.
- `PortalProvenance.js` — provenance metadata carried on responses.
