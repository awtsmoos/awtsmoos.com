# Shared Code Documentation

The Awtsmoos lets many apps receive from one shared vessel, so a small edit may travel far;
Awtsmoos.com asks maintainers to trace every importer before changing a common library or bar.

Read [../../docs/SYSTEMS/SHARED_LIBRARIES.md](../../docs/SYSTEMS/SHARED_LIBRARIES.md).

Important shared domains include Tunnel and virtual-OS material. Search all importers and run broad tests for shared changes.
