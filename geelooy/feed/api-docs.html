Developer API · v1

The routes the river itself drinks from

This page documents the exact HTTP routes the Awtsmoos River feed client calls today — nothing invented, nothing aspirational. Every endpoint below was audited from the live client code in /feed/js/. If a route is not listed here, the client does not call it.

Base URL: https://awtsmoos.com — all paths below are relative to it. Responses are JSON unless noted.

Authentication

There are no API keys. The feed APIs authenticate with the reader's Awtsmoos session cookie, exactly like the browser: every client request is sent with credentials: 'same-origin'. Call these routes from your own origin and you will be treated as signed out; call them from awtsmoos.com pages and you inherit the session.

JavaScript — session-authenticated fetch
const res = await fetch('/api/social/feed/discover?limit=20&offset=0', {
  credentials: 'same-origin'
});
if (!res.ok) throw new Error(`Feed answered ${res.status}`);
const body = await res.json();

Rate limits

The server publishes no formal rate-limit headers today. Be a good citizen: page with limit/offset instead of hammering, cache feed pages client-side for at least a minute, and keep automated polling to one request every 30 seconds or slower. Abusive clients are throttled at the edge without warning.

Feed

Ranked post lists for the river tabs and related-post rails.

GET/api/social/feed/{endpoint}

Fetch one ranked page of the river. endpoint is one of home, discover, trending. The home tab passes the viewer's alias so the server can personalize.

ParameterInNotes
limitqueryPage size, e.g. 20.
offsetqueryHow many to skip.
aliasIdqueryRequired-ish for home; the viewer's alias.
cURL
curl 'https://awtsmoos.com/api/social/feed/discover?limit=20&offset=0' \
  -H 'Cookie: <your awtsmoos session cookie>'
GET/api/social/feed/heichel/{heichelId}

Posts from a single heichel, newest first. Used by the related-posts rail.

ParameterInNotes
heichelIdpathURL-encoded heichel identifier.
limit, offsetqueryPagination, same as above.
GET/api/social/follows/{aliasId}

Aliases the given alias follows. The river uses it to re-rank the home tab client-side.

ParameterInNotes
aliasIdpathURL-encoded alias.
limitqueryThe client requests 200.
GET/api/social/activity

The viewer's recent activity ledger (the activity module reads this route).

Heichelos

Heichel metadata, series, and individual posts — what the inline reader fetches.

GET/api/social/heichelos/{heichelId}

Metadata for one heichel (display name and friends).

GET/api/social/heichelos/{h}/series/{s}

Series metadata inside a heichel.

GET/api/social/heichelos/{h}/series/{s}/details

Extended series details for the related-posts rail.

GET/api/social/heichelos/{h}/series/{s}/post/{p}

One full post — the inline reader's primary fetch.

JavaScript
const [post, series] = await Promise.all([
  fetch(`/api/social/heichelos/${h}/series/${s}/post/${p}`,
    { credentials: 'same-origin' }).then(r => r.json()),
  fetch(`/api/social/heichelos/${h}/series/${s}`,
    { credentials: 'same-origin' }).then(r => r.json())
]);

Comments

GET/api/social/heichelos/{h}/posts/{p}/comment-tree

The full comment tree for a post (nested replies included).

POST/api/social/heichelos/{h}/posts/{p}/comment-tree

Post a top-level comment. JSON body:

JavaScript
await fetch(`/api/social/heichelos/${h}/posts/${p}/comment-tree`, {
  method: 'POST',
  credentials: 'same-origin',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ content: 'Beautiful insight!', aliasId: 'my-alias' })
});
POST/api/social/heichelos/{h}/posts/{p}/comments/{parentId}/replies

Reply to a comment. Same JSON body shape as above (content, aliasId).

Reactions

GET/api/social/reactions/post/{postId}

Reaction counts, recent reactors, and the viewer's own reaction. Query: heichelId (required), aliasId (optional — include it to get viewerEmoji back).

POST/api/social/reactions/post/{postId}

Set the viewer's reaction. Note the content type: application/x-www-form-urlencoded, not JSON.

JavaScript
await fetch(`/api/social/reactions/post/${postId}`, {
  method: 'POST',
  credentials: 'same-origin',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams({ aliasId, heichelId, emoji: 'like' })
});
DELETE/api/social/reactions/post/{postId}

Remove the viewer's reaction. Query: aliasId, heichelId.

Themes

Per-heichel and per-post visual themes (the 7 feed themes, incl. parchment variants).

POST/api/social/heichelos/{h}/theme

Set the theme for a whole heichel.

POST/api/social/heichelos/{h}/posts/{p}/theme

Set the theme for one post (overrides the heichel theme).

Locales

GET/feed/js/locales/{code}.json

UI strings for the river chrome in six languages. {code} is a language code such as en or he. Static JSON — cache aggressively.

Errors

Failures come back as plain HTTP statuses; bodies are JSON with success or an error shape. What the client actually handles:

StatusMeaning
401No (or expired) session — sign in on awtsmoos.com first.
404Unknown heichel, series, post, or alias.
429Slow down — back off and retry later.
5xxServer trouble — the client retries once, then shows the empty state.

Last audited against the live client 2026-10-14. If a route above stops matching the client, the client wins — file a note and this page gets updated.
