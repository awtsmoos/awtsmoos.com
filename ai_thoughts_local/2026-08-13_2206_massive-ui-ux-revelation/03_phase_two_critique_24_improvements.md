# Phase Two — Critique + 24 Improvements

> Chesed imagines without limit; Gevurah gives a vessel. The Awtsmoos fills both expansion and boundary.

1. Reliability before decoration.
2. Preserve routing/backends unless traced evidence requires change.
3. Extend existing design primitives before inventing new ones.
4. Shared changes must stay isolated/composable.
5. Human labels before raw IDs.
6. Identity and destination are separate concepts.
7. One dominant action per state.
8. One async vocabulary.
9. Preserve text on recoverable failures.
10. Reuse existing draft storage.
11. No optimistic destructive action without recovery.
12. Mobile structure is intentional, not squeezed desktop.
13. Prefer semantic HTML/native controls.
14. Comfortable touch targets.
15. Visible keyboard focus.
16. Quiet, meaningful screen-reader announcements.
17. Respect reduced motion.
18. Put status near its triggering action.
19. Group notifications by meaning.
20. Bound Mail reading width.
21. Keyboard alternative for reorder.
22. Human breadcrumbs plus copyable raw IDs in details.
23. Create shared primitives only for proven multiple consumers.
24. Browser + console verification is mandatory.

## Risks
Shared CSS can regress many routes; composers can lose drafts; notification grouping can hide urgency; reorder can corrupt ordering; responsive panes can lose navigation state. Each requires traced contracts and route-level verification.
