# Phase Three — Final Brainstorm

> The Awtsmoos does not need complexity to reveal infinity. The final design principle is therefore radical clarity: advanced power remains present, but the ordinary path becomes obvious, calm, and recoverable.

## Final architecture
- Social Hub: preserve all eight exact target fields and deep-link semantics, but reveal them only inside a native Advanced destination disclosure. The visible path centers content, destination summary, media, and Publish.
- Notifications: preserve exact API data and read actions, but render stronger unread/read semantics, readable type labels, semantic time, and destination-aware action labels without inventing data.
- Mail: preserve sender grouping/store contracts, but make filter/search context visible, improve thread accessibility, and make empty states actionable.
- Post Editor: separate rendering from save/publish orchestration. Make destination, draft state, and publish state unmistakable while keeping save-then-publish behavior identical.
- Heichel Editor: preserve settings/invite/submission factories and endpoints, but surround them with a lightweight workbench map so governance no longer feels like three unrelated forms.

## Design law
Human intent first. Canonical control second. Local status beside the action. No hidden destructive behavior. No new backend assumptions. No page-wide rewrites when a small module owns the responsibility. No touched file above 120 lines; split instead of compressing.

## Verification law
Read back every rewritten file, run syntax checks only after the full first code pass, then open the real routes in the browser and inspect interaction state and console output.
