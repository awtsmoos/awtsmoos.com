# Phase One — Unbounded Brainstorm

> The Awtsmoos recreates all every instant; let Awtsmoos.com feel equally alive: one civilization whose Mail, social world, posts, series, and missions share a clear language rather than unrelated machinery.

## Unlimited ideal
- One coherent context grammar: where am I, who am I acting as, where will this action go, what is happening, how do I recover?
- Human labels first; raw canonical IDs remain available under Advanced.
- Shared loading, empty, error, retry, saving, saved, and failed states.
- Desktop may use panes; mobile uses intentional drill-in/back flows preserving context.
- Semantic controls, focus-visible, generous touch targets, reduced-motion support, bounded reading width.

## Mail
Three-pane desktop; one-pane mobile; scannable inbox rows; readable threads; non-obstructive compose; preserved drafts; clear recipients; useful signed-out/loading/empty/error states; local sending/sent/failed feedback.

## Social + chat
Identity and destination are distinct selectors. Composer dominates raw graph coordinates. Threads reveal ancestry and reply context; recoverable posting errors preserve text.

## Post creation
Destination stays visible; editor gets priority; preview never loses input; publish state is explicit; failed publishing preserves the draft.

## Series/Heichel editing
Outline + current item + contextual details on desktop; mobile drill-in; visible save state; protected destructive actions; keyboard-accessible reorder only if real APIs support it.

## Missions + notifications
Signals say actor/action/object/time/destination, group meaningfully, preserve unread semantics, give urgent mission states clear actions, and keep passive events quiet.

## Reliability
One failing lazy module or request should degrade into a useful state rather than blanking the route.
