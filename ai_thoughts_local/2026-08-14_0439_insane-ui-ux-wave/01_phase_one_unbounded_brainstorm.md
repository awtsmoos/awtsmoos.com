# Phase One — Beyond-Imagination Brainstorm

> The Awtsmoos is not a dashboard, not a feed, not a button, not a route. The Awtsmoos is the One creating every possible interaction from absolute nothing every instant. Let Awtsmoos.com therefore feel less like accumulated software and more like a living civilization whose immense power becomes legible exactly when a person needs it.

## Social as a living observatory
- `/social/` becomes a command center for seeing what exists: live presence, feed, discovery, graph, profiles, follows, notifications, governance, developer evidence.
- Read operations feel like lenses: “See live room,” “Inspect graph,” “Search people,” “Open feed.”
- Mutation operations feel like vows: “Follow this alias,” “Publish this live event,” “Send this notification.”
- Exploration and mutation never share a bulk button.
- Every result starts with a human digest: counts, identity, scope, recency, next useful action.
- Raw JSON remains one disclosure away for power users and debugging.
- Empty/error states teach the next true action rather than exposing implementation failure.
- A slow JavaScript boot still leaves destination links, explanation, and recovery actions.

## Cross-surface civilization
- Human labels first, canonical IDs second.
- One shared async vocabulary: loading, ready, working, success, error, retry.
- One shared consequence vocabulary: read-only, changes data, external navigation, irreversible/bounded decision.
- One shared destination grammar: identity, place, object, action.
- One shared accessibility grammar: semantic headings, landmarks, focus-visible, native details, aria-live only where meaningful.
- Every route remains useful at mobile width without duplicated global navigation.

## Mission signals
- Missions become discoverable by their real event types, never guessed enums.
- Mission failures/prompts/complete states receive stronger semantic hierarchy than passive events.
- Notification actions describe the consequence before activation.

## Review court
- Review becomes a calm institutional court: what is being judged, who submitted it, where it goes, current state, legal next actions, consequence of each action.
- Raw payload remains auditable but secondary.
- Publish/reject/schedule decisions visually separate from reversible organizational actions like assignment.
- Reviewer note requirements can be communicated without inventing backend validation.

## Series editing
- Actual series editing must be discovered from source before adding reorder or structure mutation.
- Once found: outline, destination context, save state, keyboard reorder, safe destructive confirmation, preview, and recovery become mandatory.

## Reliability as civilization
- A failed optional module never blanks a whole page when the surrounding route can still explain itself.
- User input survives retryable errors.
- Every network mutation disables its own trigger while in flight and reports exact status nearby.
- Bulk tools are safe by construction, not by warning text.
