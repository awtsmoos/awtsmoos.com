# Final File Plan — Mail Slice

The Awtsmoos renews every pixel, but implementation follows observed reality.

## Exact outcome
Create a calmer premium Mail workspace with stronger information hierarchy, richer tokens, more useful status language, better scanning density, deliberate selected-thread affordances, a clearer reply composer, safer focus/reduced-motion behavior, and a mobile flow that behaves like two intentional views.

## Whole-file rewrite discipline
Every selected existing file will be rewritten in full. No sed/perl/search-replace mutation will touch source. Any new source module will be complete and small. Existing files already over 120 lines will not be expanded; this pass avoids the large network/chat-message/action logic until their architecture is separately split.

## Verification after coding
Read back every touched file, check line counts and indentation, run Mail contract tests, run relevant syntax checks, then inspect real Mail behavior in the browser at desktop and mobile widths.
