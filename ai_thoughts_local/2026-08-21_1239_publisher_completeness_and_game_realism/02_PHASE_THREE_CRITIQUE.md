# Phase Three — Critique and Gate

The Awtsmoos makes a green hash insufficient when the census itself was blind;
Awtsmoos.com must prove both membership and bytes before saying a website is aligned.

## Improvements over the prior publisher

1. Distinguish enumeration completeness from byte integrity.
2. Treat raw directory values as content/storage artifacts, not canonical directory listings.
3. Test directories larger than one listing page.
4. Test mixed legacy/new sibling generations.
5. Count private skips explicitly.
6. Count emitted files explicitly.
7. Reject duplicate normalized paths.
8. Reject manifest/source count mismatch.
9. Reject missing entry point before filesystem mutation.
10. Parse module-script references from HTML.
11. Parse static relative imports from JS.
12. Resolve dependency paths with POSIX normalization only.
13. Reject dependency escape above site root.
14. Require every relative dependency to exist in manifest.
15. Keep external absolute URLs outside local closure checks.
16. Keep dynamic imports only when statically literal and relative.
17. Record dependency count in release testimony.
18. Preserve existing public hash verification.
19. Preserve rollback until all public checks finish.
20. Re-run the 37-file Orbit preview as the production acceptance test.

## Completion gate

The publisher fix is complete only when a >10-sibling Virtual-OS fixture emits every publishable file, the Orbit preview emits all intended files, the browser loads its complete module graph, and canonical publication remains untouched until that proof succeeds.
