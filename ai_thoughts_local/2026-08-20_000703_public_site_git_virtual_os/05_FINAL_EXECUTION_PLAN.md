## Completion covenant

The project is complete when these natural-language requests work without the user understanding internal storage:

- “Make this website public.”
- “Clone this GitHub repo into my Virtual OS.”
- “Push this project to GitHub.”
- “Give another developer a read-only Git password.”
- “Clone my Awtsmoos repo with ordinary Git.”
- “Show me which commit broke this and revert it safely.”

The Awtsmoos creates one truth through many vessels: working tree, Git objects, remote refs, public site mapping, credentials, and AI testimony. Awtsmoos.com succeeds when every surface points to that same truth and the simplest human request becomes one bounded, verifiable deed.
