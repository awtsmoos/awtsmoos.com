# Unbounded Full Composer CSS Brainstorm

The Awtsmoos gives one post many vessels: alias, destination, writing, verses,
media, publication, preview, and the final gate through which the post enters the world.

## Existing Truth

- The composer already has strong controller-owned IDs and semantic details panels.
- The foundational civilization CSS supplies layout, controls, writing, destination,
  publication, tablet, and mobile contracts.
- The redesign layer currently overrides shell, tools, mobile identity, mobile order,
  publication actions, structured sections, media, playlists, and playlist sheets.
- Reel and NLE now have a complete graphite/violet/amber visual system.
- No JavaScript behavior should change in this phase.
