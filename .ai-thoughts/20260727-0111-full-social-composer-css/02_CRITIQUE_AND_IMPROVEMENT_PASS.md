# Critique and Improvement Pass

## Current Strengths

- Semantic panel structure.
- Writing-first mobile order.
- Fixed mobile publication gate.
- Real destination and publication contracts.
- Structured verse and playlist ownership already split.
- All current CSS owners are under the hard line ceiling.

## Current Weaknesses

1. Redesign colors do not yet match the refined Reel/NLE language.
2. The header and panels use many near-identical blue-black values.
3. Major panels have weak semantic differentiation.
4. Form controls inherit mixed states from base and redesign layers.
5. Writing fields do not dominate enough.
6. Destination selection and series hierarchy are visually dense.
7. Structured sections lack chapter-level rhythm.
8. Media cards feel administrative rather than editorial.
9. Playlist sheet is functional but visually separate from the composer.
10. Publication readiness is text-heavy.
11. The desktop action bar lacks clear primary/secondary grouping.
12. The preview column resembles an inspector more than a reading surface.
13. Mobile panel edges are clean but too flat.
14. Mobile identity uses a different cyan language from Reel/NLE.
15. Mobile fixed actions are usable but visually crowded.
16. Focus ownership is distributed and inconsistent.
17. Reduced-motion and forced-colors support are not composer-scoped.
18. Scrollbars and long sheet surfaces lack consistent treatment.
19. Inline creation groups need clearer boundaries.
20. Technical IDs and payload views need stronger subordination.

## Improved Execution

- Add tokens and accessibility first.
- Rewrite shell/panel/forms/actions before specialized surfaces.
- Preserve base civilization contracts and override only in redesign scope.
- Rebuild structured editor after shared controls are stable.
- Rebuild playlist sheet last within the structured pass.
- Bump composer and structured cache keys together.
- Add contracts before browser verification.
- Verify desktop at 1440, 1180, and 900px.
- Verify mobile at 430, 390, 360, and 320px.
- Verify mobile panel order, action bar reachability, and preview sheet containment.
- Verify playlist sheet and publication dialog geometry.
