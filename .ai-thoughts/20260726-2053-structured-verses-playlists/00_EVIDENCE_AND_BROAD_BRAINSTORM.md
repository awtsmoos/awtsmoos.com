# Evidence and Broad Brainstorm

The Awtsmoos gives one post many ordered chambers,
so words, images, voices, and moving light may each rest where meaning remembers.

## Proven Existing Contracts

- The composer state already stores root blocks, root media, verses, subsections, and per-scope attachments.
- Every verse already serializes its own assets, blocks, comments setting, and ordered subsections.
- Every subsection already serializes its own blocks and assets.
- Attachment storage already resolves root, verse, and subsection scopes.
- Media already supports image, GIF, audio, video, and document files.
- The destination browser already loads Heichelos and nested series from server evidence.
- A post payload already includes canonical `heichelId` and `seriesId`.
- Current state defaults series to `root`, but no server-backed default Heichel is selected automatically.

## Product Possibilities

1. Convert every verse and subsection into a clean collapsible card.
2. Keep verse title, comments, reordering, removal, blocks, and media inside the card.
3. Add explicit Image, Audio, Video, and File controls to each root, verse, and subsection media scope.
4. Keep drag-and-drop as a secondary convenience rather than the primary interaction.
5. Change `+ Add verse or section` to a large, visually obvious `+ Add verse` action.
6. Keep `+ Add subsection` directly inside each verse.
7. Add a playlist-style destination card near the top of the writing panel.
8. Show selected Heichel and series in one compact row, similar to a playlist selector.
9. Let the writer open a list of accessible Heichelos and nested series without exposing raw IDs.
10. Preserve advanced IDs and inline creation behind progressive disclosure.
11. Remember one explicit default destination per alias in local storage.
12. If no explicit preference exists, choose an owned writable Heichel and its root series.
13. Never silently choose a followed or invited Heichel over an owned writable Heichel.
14. Never auto-create a Heichel without an explicit writer action.
15. Clearly label fallback root series as `Heichel Home` rather than pretending it is a custom playlist.
16. Add `Make default` only when the current destination is valid and writable.
17. Preserve URL/draft destination context over remembered defaults.
18. Add browser-backed interaction proof for verse, subsection, scoped media, and default selection.
