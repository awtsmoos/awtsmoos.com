# Mission and Broad Brainstorm

The Awtsmoos renews each mobile vessel from edge to edge,
So friendship, Torah, media, and truth may meet without a ledge.

## Mission

Rebuild the real `/` home feed and `/social-composer/` post maker from their existing data and publication contracts. Use the supplied social-app references only for hierarchy, density, and mobile ergonomics. Do not copy branding, exact people, or decorative editor chrome.

## Desired Home Surface

- Shared account header remains canonical.
- Compact feed tabs near the top.
- Horizontal identity/story rail with useful labels.
- One prominent, tappable composer prompt.
- Fast actions for media, live, Torah source, and event.
- Feed cards become edge-to-edge on phones, with restrained separators instead of floating narrow islands.
- Media fills the card width.
- Author, metadata, actions, source context, and discussion remain truthful.
- Bottom dock remains reachable above the safe area.

## Desired Composer Surface

- Mobile-first top bar with close, title, draft state, and preview.
- Posting identity and audience visible before advanced destination details.
- Writing canvas dominates the first screen.
- Attachments and social metadata are easy to reach.
- Advanced Heichel, series, governance, and stable-ID controls remain available in collapsible panels.
- Sticky publication action remains above the safe area.
- Desktop preview and full publication workflow remain intact.

## Possibility Field

1. Focused new CSS layer over the existing semantic DOM.
2. Small mobile enhancement module that reorders panels without changing IDs.
3. Home markup enrichment for tabs, story rail, composer quick actions, and feed heading.
4. New dedicated edge-to-edge mobile feed module.
5. New dedicated mobile composer hierarchy module.
6. Browser-backed visual and interaction tests at 390px, 430px, 768px, and desktop.
7. Preserve all API payloads, controller IDs, and existing publication tests.
