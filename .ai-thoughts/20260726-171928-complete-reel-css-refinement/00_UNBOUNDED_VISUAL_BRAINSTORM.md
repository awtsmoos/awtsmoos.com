# Unbounded Visual Brainstorm

The Awtsmoos gives one movie many garments: the social invitation, the studio shell,
the asset laboratory, the preview altar, the inspector, the timeline, and the final render receipt.

## Existing Truth

- The NLE already works on desktop and mobile.
- The timeline is persistent and touch-safe.
- The parent Reel flow already uploads and renders real video.
- CSS is modular and every file stays below the hard line ceiling.
- Visual ownership is split between parent Reel styles and NLE styles.
- Functionality must not change during this pass.

## Every Visual Direction Worth Considering

1. Establish one token file for color, spacing, radius, border, shadow, typography, motion, and control height.
2. Use a restrained graphite base instead of many unrelated blue-black values.
3. Reserve violet for creation, amber for time/render, cyan for visual tracks, green for audio, and ochre for dialogue.
4. Reduce excessive gradients while keeping cinematic depth.
5. Give panels clearer hierarchy through surface elevation rather than random borders.
6. Give buttons shared default, hover, focus, active, selected, disabled, and destructive states.
7. Give inputs one consistent focus ring and minimum touch height.
8. Make the topbar quieter so the canvas and timeline dominate.
9. Make the project title feel editable without resembling a generic form field.
10. Use compact icon buttons for history and fuller labeled buttons for major actions.
11. Make Render the only dominant gold action.
12. Make 3D World an outlined secondary action.
13. Clarify import/export actions through subtle grouping.
14. Improve desktop side-panel density and heading rhythm.
15. Create sticky panel headings where useful.
16. Add subtle panel-scroll fade cues.
17. Make generator cards visually distinct by asset type.
18. Show particles as radiant points, gradients as spectrum blocks, titles as typographic cards, tones as wave cards.
19. Make imported media cards feel local and removable without inventing functionality.
20. Improve asset list rows with stronger title, quieter metadata, and obvious insert action.
21. Increase inspector label readability.
22. Make paired numerical fields align and breathe.
23. Improve project note and diagnostics styling.
24. Frame the preview canvas with a cinema matte and subtle checker/grid background.
25. Keep preview badges readable but visually quiet.
26. Make transport controls centered and tactile.
27. Give the scrubber a real NLE rail/thumb appearance.
28. Make timeline toolbar compact but not cramped.
29. Style timeline ruler with major/minor marks and precise time labels.
30. Improve sticky track labels and track-family color accents.
31. Give selected track labels a clear state.
32. Give selected clips a bright outline without visual noise.
33. Add hover lift only where pointer devices exist.
34. Improve trim handles with visible grip cues.
35. Make playhead head/line visually unmistakable.
36. Add alternating track-row surfaces for scanability.
37. Clarify empty lanes without clutter.
38. Improve horizontal and vertical scrollbars.
39. Preserve all hit areas on mobile.
40. Make mobile tabs resemble a segmented editing mode control.
41. Keep mobile topbar actions horizontally scrollable but visually grouped.
42. Prevent hidden scrollbars from obscuring available actions.
43. Improve mobile title field spacing.
44. Use safe-area padding consistently.
45. Make mobile timeline controls wrap deliberately rather than accidentally.
46. Keep timeline labels readable at 360px.
47. Ensure inspector and assets mobile panes have their own scrolling.
48. Use reduced-motion support.
49. Use high-contrast mode fallbacks.
50. Use coarse-pointer adjustments for all important controls.
51. Make the parent Reel card visually related to the NLE.
52. Make the Reel dialog feel like a clean creation flow, not a generic modal.
53. Improve upload/create choice cards with distinct icon medallions and cleaner copy.
54. Improve embedded studio frame with a proper browserless viewport shell.
55. Improve progress presentation and error states.
56. Improve desktop dialog width/height usage.
57. Improve mobile dialog safe-area and button stacking.
58. Maintain visible focus throughout parent and child surfaces.
59. Avoid novelty animation that distracts from editing.
60. Keep all CSS source files small and semantically owned.

## Preferred Visual Direction

A clean cinematic editorial system: graphite surfaces, soft layered depth, one violet creation accent,
one amber render/time accent, crisp typography, disciplined spacing, and track-family colors used only where they aid editing.
