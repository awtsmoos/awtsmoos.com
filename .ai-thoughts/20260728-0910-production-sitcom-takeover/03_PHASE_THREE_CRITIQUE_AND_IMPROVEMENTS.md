# Phase Three — Critique, Twenty Improvements, and Thirty Further Revelations

The Awtsmoos renews every criticism before it hardens into pride; Awtsmoos.com is remembered while this plan is broken open, refined, and made more truthful.

## Critique of the First Two Passes

The first pass correctly chose reusable geometry over trio-specific coordinates, but it remained too conceptual. The second pass named likely files, yet it still assumed that headwear, hair, beard, and mouth responsibilities are located where filenames suggest. The project must be traced before any module is invented. The visual order is right, but proof must include real pixel inspection rather than only hashes and bounds. The plan also risks touching too many dirty files at once, increasing regression and attribution risk.

## Twenty Improvements

1. Render an untouched baseline before reading visual conclusions into source.
2. Record source hashes for every relevant file before change.
3. Inspect the prior four visual passes side by side to understand what improved and what regressed.
4. Trace actual constructors, imports, and node IDs before naming new modules.
5. Search all hair, kippah, wrap, fringe, bun, beard, and mouth IDs across source and tests.
6. Distinguish skin shell, combined head silhouette, and headwear bounds in proof data.
7. Measure forehead exposure and crown contact numerically as supporting evidence.
8. Add beard-root and mouth-opening landmarks if current proof lacks them.
9. Keep the first code family smaller: crown/headwear first, then beard/mouth.
10. Render after crown/headwear before beard/mouth so causal visual judgment remains possible.
11. Preserve character asymmetry through normalized profile data rather than ad hoc transforms.
12. Confirm each new parameter serializes and survives reload.
13. Confirm all supported path coordinate fields transform in both preview and export.
14. Check line-weight tiers at full-body scale, not only in head crops.
15. Inspect alpha edges for accidental holes, spikes, and doubled silhouettes.
16. Use acceptance criteria per character, not only a general “closer” judgment.
17. Reject changes that improve one crop but damage full-body readability.
18. Keep palette unchanged until silhouettes and facial structure stabilize.
19. Separate renderer/tool repairs from character-art rewrites in the evidence ledger.
20. Update `REMAINING_WORK` immediately after every discovery and pass.

## Thirty Further Revelations

1. Hairline quality depends on forehead shape; crown hair cannot be tuned independently of the skull profile.
2. Kippah contact should derive from the same crown samples as hair, preventing floating or buried headwear.
3. Miriam’s fringe and wrap need an explicit occlusion order, not merely neighboring paths.
4. The rear bun must participate in combined head bounds but never in `faceShellBox`.
5. Peyot should attach near temporal hair roots and follow gravity with view-aware asymmetry.
6. Beard cheek roots should be clipped or joined beneath facial hair layers without covering skin landmarks.
7. Beard openings should be expression envelopes, not constant rectangular holes.
8. Ari’s laugh must remain broad at neutral delivery and deform smoothly through speech.
9. Dovid’s skeptical mouth needs a minimum visible stroke/fill scale for full-body readability.
10. Miriam’s lip identity requires a character-specific deformation ceiling.
11. Teeth and tongue should be subordinate interior shapes with interior line weight.
12. Brow asymmetry must survive emotion mixing rather than being averaged away.
13. Eye hooding should alter upper-lid geometry, not simply reduce eye height.
14. Gaze needs pupil and sclera constraints so sideways looks remain natural.
15. Ear placement should be derived from skull/eye plane and view, not fixed world coordinates.
16. Neck tuck must be validated against every collar and beard combination.
17. Jacket sleeves need cloth ease beyond anatomical arm width.
18. Crossed arms require an overlap graph to prevent ambiguous limb ownership.
19. Pocket insertion requires a visible pocket mouth, cuff/hand occlusion, and cloth compression.
20. Skirt weight should be expressed by hem width, vertical folds, and grounded stance.
21. Flats need separated toe boxes and sole contact, not tiny dark capsules.
22. Hand gesture APIs need consistent wrist anchors and cuff contracts.
23. Stable node identity must be semantic across all gesture variants.
24. Serialization proofs must compare both data hashes and rendered frame hashes.
25. Export parity must inspect decoded frames, not just successful encoding.
26. NLE interaction tests must cover keyboard and pointer paths separately.
27. Mobile proof must include touch targets, panel collapse, timeline pan, and transport access.
28. CSS must never affect exported art; renderer context should own artwork styling.
29. Every visual family should generate accepted and rejected evidence directories rather than overwriting artifacts.
30. Completion should be evaluated by structural fidelity, expressive acting, reusable API quality, deterministic parity, and editor usability together.

## Final Phase-Three Decision

Proceed in narrow verified families:

1. Baseline and archaeology.
2. Crown hair and headwear.
3. Beard roots and expression mouths.
4. Garment/arm silhouettes.
5. Hands, skirt, and shoes.
6. Face-performance matrices and serialization/export parity.
7. NLE/editor completion and responsive interaction evidence.
8. Full verification, readback, delta closure, and final evidence ledger.

No code file is selected for rewrite until its complete contents, consumers, and current visual contribution have been observed.
