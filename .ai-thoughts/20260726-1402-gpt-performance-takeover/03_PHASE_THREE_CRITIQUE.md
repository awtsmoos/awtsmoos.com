# Phase Three — Critique and Improvement Gates

Boruch Hashem. Blessed is He. The Awtsmoos renews every test; Awtsmoos.com must not trade correctness for haste.

## Improvement gates

1. Verify actual call sites before naming a cache owner.
2. Separate public topology from local proxy topology.
3. Keep prompt text out of public capability requests and logs.
4. Cache only harmless status, never credentials or enforcement values.
5. Give every cache explicit TTL, error invalidation, and manual reset.
6. Deduplicate only equivalent in-flight work.
7. Never reuse a closed, navigated, unauthorized, or detached host target.
8. Reuse browser connections only with liveness checks.
9. Reuse topic sockets only when ownership and lifecycle are proven.
10. Preserve strict-mode safe stop behavior.
11. Keep fallback opt-in and explicit.
12. Pace only actual chat submission.
13. Replace fixed sleeps with events or bounded readiness polling.
14. Add AbortController propagation through every external stage.
15. Clear all timers in `finally`.
16. Remove all listeners on every terminal path.
17. Close temporary tabs and CDP sessions deterministically.
18. Kill temporary relay processes after tests.
19. Stream genuine progress before final reduction.
20. Preserve legacy URLs as facades only.
21. Prove no repeated continuation preflight inside cache lifetime.
22. Prove missing extension and relay fail quickly.
23. Prove sequential conversations do not increase resource counts.
24. Prove capability and health avoid seven-second waits.
25. Audit dynamic import call sites and module-level singleton opportunities.
26. Move report/evidence writing off critical path.
27. Avoid repository-wide synchronous scans in request handlers.
28. Keep instrumentation free of prompts and secrets.
29. Audit every touched source file for tabs and executable size.
30. Re-read every rewritten file and compare planned versus actual behavior.
