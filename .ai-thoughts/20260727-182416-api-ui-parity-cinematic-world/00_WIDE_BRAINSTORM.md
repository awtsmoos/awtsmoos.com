# Wide Brainstorm: API/UI Parity and Cinematic World

## Core Requirement

Every callable movie action must have a visible UI control, and every generated UI
control must invoke the same action catalog used by the public API. No duplicated
switch statements, undocumented magic buttons, or API-only capabilities.

## Cinematic World Possibilities

1. Procedural village with houses, roofs, windows, paths, and fences.
2. Deterministic tree groves with trunks, crowns, wind, and depth layers.
3. Walking lead character with authored path, pause, turn, and reveal moments.
4. Secondary silhouettes to create lived scale without inventing identity.
5. Camera rigs: dolly, crane, orbit, side track, handheld drift, aerial pullback.
6. Motivated dawn, blue-hour, moonlight, doorway, and window lighting.
7. Wet ground, stone, wood, plaster, leaf, cloth, and emissive-window materials.
8. Shader graphs for sky gradient, fog, sun, wind, exposure, and vignette.
9. GPU particle graphs for dust, rain, pollen, sparks, and fireflies.
10. Real WebGL offscreen render composited into the existing NLE canvas.
11. 2D fallback when WebGL is unavailable or context is lost.
12. Reduced-motion and low-power quality tiers.
13. Same frame used by preview, playback, MediaRecorder, and social attachment.
14. Ready-to-go agent request, movie package, graph, asset, and validation formats.
15. Connected-provider hook without fabricating an AI service or credential.

## API/UI Action Possibilities

- Ask connected agent or build request package.
- Load cinematic village.
- Add house.
- Add tree grove.
- Animate character walk.
- Add camera shot.
- Add material graph.
- Add shader graph.
- Add particle graph.
- Validate movie.
- Export movie package.
- Apply movie package.
- Play, pause, seek, render, open 3D World.
- Load starter, use current, copy schema, copy JSON, download, apply JSON.

## Important Constraints

- Preserve canonical MitzvahWorld project fields.
- Preserve existing recorder, rendering, autosave, history, and social attachment.
- Never overwrite unrelated MitzvahWorld gameplay work.
- Never claim photoreal external media was generated locally.
- Every source, style, test, and documentation owner stays below 120 lines.
- All source modifications are complete-file rewrites.
