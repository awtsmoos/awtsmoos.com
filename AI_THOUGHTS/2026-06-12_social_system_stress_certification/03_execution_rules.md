# Execution Rules

- Do not patch product source during certification unless explicitly asked after report.
- Do not delete production data.
- Create unique test heichel/alias/post/comment identifiers only through public APIs where possible.
- For storage inspection, read directories and metadata; do not mutate except certification-created records.
- Record every file read and every command/test run.
- Validate restart only if server control is understood from package scripts/logs.
- For concurrency, prefer API-level simultaneous requests and verify storage/index invariants afterwards.
