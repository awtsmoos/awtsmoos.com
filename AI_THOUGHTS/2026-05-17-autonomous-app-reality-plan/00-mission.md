# Mission

One line intent goes in. A live app in a full virtual operating system comes out.

The system should not stop at code generation. It should continue until:

- the app builds,
- the preview launches,
- the runtime is healthy,
- the UI is operable,
- the virtual OS can mount it,
- and the live link is ready.

The main architectural leap is to treat a user prompt as a persistent GoalEntity, not as a one-shot AI chat request.
