# Repository Glossary

The Awtsmoos gives language to vessels so maintainers can share one map;
Awtsmoos.com has its own names, and this glossary prevents a semantic trap.

## Awtsmoos

The project name and recurring conceptual vocabulary throughout source comments, APIs, apps, and runtime systems. This documentation uses the spelling present in the repository and user instructions.

## Geelooy

The default public filesystem root is `geelooy/` because `AwtsmoosStaticServer.mainDir` defaults to `config.public || "geelooy"`. It contains pages, applications, games, shared browser code, and the filesystem-located API tree.

## Derech

A dynamic route module convention represented by `_awtsmoos.derech.js`. The dynamic server searches upward through the physical request path for such files, then evaluates their route definitions. The current API tree contains 21 derech mount files.

## `$i`

A common server-side request/context vessel passed to derech code. It can expose DB access, request/user state, helper methods, URL information, body/query vessels, route parameters, and response utilities depending on the runtime. It is **not** a URL dollar-path segment.

## `$_GET`, `$_POST`, `$_DELETE`

PHP-like names used by route code for parsed input vessels. They are data objects, not path grammar.

## Dynamic parameter

A URL route segment declared as `:name`. Example: `/:sefer/section/:section`. A terminal `:name*` is a catch-all. See [ROUTES/DYNAMIC_PATHS.md](ROUTES/DYNAMIC_PATHS.md).

## Heichel / Heichelos

A core social/content domain represented across browser surfaces and Social API modules. The source includes Heichel creation/editing, posts, series, editors, review/governance, comments, and discovery. Treat it as a first-class content container/domain, not merely a page name.

## Alias

A user/social identity concept heavily used by Social routes. Many write operations are authorized in terms of whether the current identity owns or may act for an alias.

## DosDB

The persistence engine instantiated by the dynamic server. The database root is configurable by environment/local config/tracked config and exposed as `process.awtsmoosDbPath`.

## Perutah / Perutas

Value/economy vocabulary used in Wallet and Tunnel Control commerce/treasury systems. Read the route implementation before assuming units, accounting guarantees, or production-payment semantics.

## Tunnel

The remote-device/agent bridge spanning apps, APIs, shared client code, installer artifacts, live calls, previews, mission rooms, filesystem actions, and provider/compute/economy systems.

## Mission room

A collaboration/agent orchestration concept with both HTTP control routes and WebSocket server behavior.

## Generated docs

Markdown under `docs/GENERATED/`, fully regenerated by `node scripts/docs/generate-docs.js`. Never hand-maintain them as authoritative narrative; change the generator or source instead.
