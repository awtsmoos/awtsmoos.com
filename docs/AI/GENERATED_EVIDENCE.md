# Generated Evidence Catalog

The Awtsmoos lets exhaustive evidence be renewed mechanically while Awtsmoos.com keeps interpretation in human hands.

## API evidence

- `API_ROUTE_ATLAS.md` — route pattern to source.
- `API_ROUTE_CONTRACT_ATLAS.md` — route plus best source-level method/vessel/status/header evidence.
- `API_SOURCE_CONTRACTS.md` — source-file contract evidence.
- `API_CALLER_INDEX.md` — literal browser/test callers.
- `API_FAMILY_SUMMARY.md` — mount-level counts/health.
- `DERECH_HEALTH.md` — `node --check` per derech.
- `DYNAMIC_PARAMETER_INVENTORY.md` — parameterized route rows.

## Project and source evidence

- `PROJECT_ATLAS.md` — observed project/directory boundaries and classified file counts.
- `PROJECT_SYMBOL_SUMMARY.md` — project-level lexical classes/functions/exports plus representative names.
- `PROJECT_DEPENDENCIES.md` — cross-project relative-import evidence.
- `EXTERNAL_DEPENDENCIES.md` — package import evidence grouped by project.
- `SYMLINKS.md` — alias/symlink paths.

## Browser evidence

- `PUBLIC_ENTRY_POINTS.md` — public URL, `index.html`, title, script and style references.
- `PUBLIC_ROUTE_INVENTORY.md` — immediate Geelooy directory inventory.
- `APP_INVENTORY.md` — immediate apps.

## Realtime evidence

- `WEBSOCKET_APPLICATIONS.md` — registered realtime applications/versions and source directories.
- `WEBSOCKET_EVENT_INDEX.md` — lexical production-source event/message strings.

## Test, configuration and documentation evidence

- `TEST_SCRIPT_INDEX.md` — package scripts.
- `TEST_OWNERSHIP.md` — test-file counts by project boundary.
- `ENVIRONMENT_VARIABLES.md` — names and source ownership, never values.
- `DOCUMENTATION_COVERAGE.md` — local documentation requirement/status.
- `MISSING_DOCUMENTATION.md` — meaningful uncovered boundaries.
- `HUMAN_DOCUMENTATION_INDEX.md` — manual Markdown inventory.

## Machine-readable evidence

`docs/AI/MANIFEST.json` and `docs/AI/PROJECTS/*.json` are generated companions. They point to canonical human docs and generated indexes; they are not a second source of business truth.

## Interpretation rule

Generated evidence is best used as a locator and change detector. When behavior matters, follow the source path, inspect runtime/data/auth dependencies, and run the relevant tests before claiming the contract is verified.
