# Search, Graph, and Discovery

Social discovery spans more than one search endpoint.

## Search families

General search/query/index/readiness, Hebrew exact/Tanach search, comment lexical/vector/stress/stats, RAG status/context routes, feeds/trending/recommendations, and object/graph/reference/repost relationships.

## Evidence discipline

Generated routes reveal entry points, not ranking semantics, embedding models, index freshness, or relevance guarantees. Follow owning search/RAG source and configuration names.

## Graph/object layer

Entity/object/universe/relationship routes expose identity, edges, timeline, children, DNA/snapshot/fork/reference concepts. Treat them as explicit models, not synonyms for raw database paths.
