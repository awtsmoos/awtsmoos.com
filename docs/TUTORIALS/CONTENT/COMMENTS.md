# Comments and Replies

Comments attach to posts and richer substructures; replies/reactions/comment trees form their own navigation domain.

## Surfaces

- post comment collections;
- aliases contributing comments;
- singular comment routes;
- nested replies;
- reactions;
- subsection/verse comments;
- submitted-comment moderation;
- comment search/ranking/vector/RAG evidence.

## Compatibility

Some comment routes appear more than once in generated extraction because multiple route objects/factories expose compatible paths. Use source ownership to distinguish implementations.

## Moderation

Approval/denial/submitted-comment flows are separate from ordinary comment read/write behavior.
