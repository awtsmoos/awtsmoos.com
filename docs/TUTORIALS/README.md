# Awtsmoos.com Tutorials

The Awtsmoos lets a tutorial explain *why and how* while generated evidence answers *which files and routes exist right now*.

## API families

[TUTORIALS/API/](API/) contains one manual for every currently cataloged derech family. These pages explain ownership, trust boundaries, interpretation, and how to descend into the generated route tutorials without copying volatile route tables by hand.

Use [../GENERATED/API_FAMILY_TUTORIALS.md](../GENERATED/API_FAMILY_TUTORIALS.md) for regenerated family counts/health and [../GENERATED/API_TUTORIAL_INDEX.md](../GENERATED/API_TUTORIAL_INDEX.md) for every route.

## Server and runtime

[TUTORIALS/SYSTEMS/](SYSTEMS/) teaches server boot, request pipeline, dynamic routing, identity/authorization, DosDB runtime, realtime runtime, and the documentation runtime itself.

## Content platform

[TUTORIALS/CONTENT/](CONTENT/) teaches the Social content model, Heichel governance, posts/series, comments, aliases/API keys, moderation, search/graph/discovery, mail/notifications/Drive, and migrations.

## Foundation curriculum

If the repository is unfamiliar, start with [../LEARN/README.md](../LEARN/README.md) rather than entering a specialist tutorial in the middle.

## Evidence rule

Manual tutorials describe inspected meaning and workflows. Generated tutorials describe source-derived evidence. Neither replaces current implementation/tests when exact runtime behavior matters.
