# Data, Security, and Realtime System Tutorials

These tutorials teach how to reason across subsystem boundaries that cannot be understood from one route or one project directory alone.

## Three districts

- **Data and Persistence** — storage roots, DosDB, AwtsmoosBinaryJSON, AwtsmoosDB/VirtualFs, Social packed storage, path contracts, and migration risk.
- **Security and Trust** — sessions, OAuth/API-key identity, authorization, ownership/grants, secret/config names, and realtime admission.
- **Realtime and WebSockets** — socket upgrade/session, application routing, Mission Rooms, Tunnel Relay, and lexical application/event evidence.

Use `/docs/?view=systems` for the interactive evidence map and [Generated System Tutorial Index](../../GENERATED/SYSTEM_TUTORIAL_INDEX.md) for one generated packet per stable system concept.

## Evidence rule

Generated environment evidence contains variable **names**, classifications, source-reference counts, and example source paths only. It never reads values. WebSocket event strings are lexical search clues, not protocol schemas. Security packets are navigation aids, not security-audit findings.
