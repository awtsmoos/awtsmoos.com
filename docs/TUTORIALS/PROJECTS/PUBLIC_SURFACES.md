# Public and Other Boundaries

This family contains public/public-root/project boundaries plus alias/evidence roots that do not fit the narrower app/API/game/runtime/library families.

## Read the exact type first

- `public` / `public-root` can represent broad browser-facing roots.
- `project` is a discovered boundary without a more specific classification.
- `alias` can represent a symlinked compatibility/navigation boundary.
- `evidence` can represent planning/discovery material and is not a product surface.

## Investigation strategy

Use the generated tutorial’s exact path/type, symlink target, public entries, local docs, file counts, and dependency evidence. Do not convert an evidence root into a product simply because it is large. Do not treat a symlink alias as an independent implementation without inspecting its target.
