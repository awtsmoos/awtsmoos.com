## Generated project teaching

[Project Tutorial Index](../../GENERATED/PROJECT_TUTORIAL_INDEX.md) gives one generated tutorial for every current project boundary. Each project tutorial joins file shape, entries, local docs, public URLs, lexical symbol summaries, incoming/outgoing dependencies, external packages, and test-file evidence.

## Evidence rule

Imports are lexical dependency evidence, not runtime call graphs. `index.html` means a public entry file was found, not that the application is healthy. Test-file counts are not behavioral coverage scores. Generated packets point you toward source and verification; they do not replace either.
