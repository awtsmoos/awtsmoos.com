## Evidence rules

Generated application rows reflect source registration, not deployment health. Event/message strings are lexical search clues, not formal payload schemas. Mission Room tickets/origin/protocol/snapshot checks and Tunnel Relay registration/correlation are specialized trust/transport contracts and should not be collapsed into ordinary app routing.
