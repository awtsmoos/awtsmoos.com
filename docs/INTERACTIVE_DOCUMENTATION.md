# Interactive Documentation Application

`/docs/` converts intentional documentation and bounded generated evidence into a safe browser experience without making the publication itself authoritative over source.

## Primary modes

### Learn — `/docs/?view=learn`
Five source-backed tracks with local-only completion state.

### API Explorer — `/docs/?view=api`
Routes, method/source/caller/test evidence, family/health/shape/confidence filters, deep links and Ask.

### Project Explorer — `/docs/?view=projects`
Project boundaries, entries, file shape, symbols, dependencies, tests, docs, public surfaces and Ask.

### Systems Explorer — `/docs/?view=systems`
Curated Data/Security/Realtime concepts with district/evidence/text filters, claims boundary, change risk, human/generated docs, project links, copyable source anchors, environment **names only**, registered realtime applications, lexical events, deep links and system-aware Ask.

### Documents
Global search, safe Markdown reading, provenance, favorites/recents, deep links and retrieval-first Ask.

## Publication v6

`geelooy/docs/generated/manifest.json` declares transport-bounded search, project, system, API tutorial, page, and content shards. The browser guesses no shard names.

## Safety

Raw Markdown HTML is not executed. Authored modules do not assign `innerHTML`. System packets never publish environment values. Event literals remain lexical clues. Project/API/system evidence does not replace source verification.
