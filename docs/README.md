# Awtsmoos.com Documentation

The Awtsmoos lets one repository be understood through human meaning, exhaustive route/project evidence, stable system contracts, current source, and verification.

## Fastest doorway — `/docs/`

The public documentation application has five primary modes:

- **Learn** — five source-backed curricula with browser-local progress.
- **API Explorer** — every discovered API route with method/source/caller/test evidence.
- **Project Explorer** — every current project boundary with entries, dependencies, symbols, tests, docs, and public surfaces.
- **Systems Explorer** — curated Data, Security, and Realtime contracts joined to bounded project/source/environment/application/event evidence.
- **Documents** — global search, safe Markdown reading, provenance, favorites/recents, deep links, and retrieval-first Ask.

Open `/docs/?view=learn`, `/docs/?view=api`, `/docs/?view=projects`, or `/docs/?view=systems` directly.

## Human learning

Start at [LEARN/README.md](LEARN/README.md). Deeper tutorials live under [TUTORIALS/README.md](TUTORIALS/README.md), including API families, projects, content, and [Data/Security/Realtime system workflows](TUTORIALS/SYSTEMS/README.md).

## Generated teaching

- [API Tutorial Index](GENERATED/API_TUTORIAL_INDEX.md) — one generated tutorial per current route.
- [Project Tutorial Index](GENERATED/PROJECT_TUTORIAL_INDEX.md) — one generated tutorial per current project boundary.
- [System Tutorial Index](GENERATED/SYSTEM_TUTORIAL_INDEX.md) — one generated tutorial per curated stable system concept.
- [System District Summary](GENERATED/SYSTEM_DISTRICT_SUMMARY.md) — current Data/Security/Realtime evidence summary.

Generated evidence stays conservative. Unknown HTTP methods stay unknown. Project imports/events are lexical clues, environment evidence contains **names only**, and system packets are not security audits or persistence/protocol guarantees.

## Enter by task

- URL/API → [API/README.md](API/README.md) → route tutorial → source/tests/runtime.
- Directory/project → [PROJECTS/README.md](PROJECTS/README.md) → project tutorial → dependencies/entries → source.
- Persistence/trust/realtime contract → [TUTORIALS/SYSTEMS/README.md](TUTORIALS/SYSTEMS/README.md) → system tutorial → source/project/tests/runtime.
- Data → [DATA/README.md](DATA/README.md).
- Security → [SECURITY/README.md](SECURITY/README.md).
- WebSockets → [WEBSOCKETS/README.md](WEBSOCKETS/README.md).
- AI discovery → [AI/README.md](AI/README.md), [AI/MANIFEST.json](AI/MANIFEST.json), [AI/SYSTEMS/MANIFEST.json](AI/SYSTEMS/MANIFEST.json), and root `llms.txt`.

## Authority order

Human manuals explain meaning and risk. Generated route/project/system packets enumerate changing evidence. AI packets provide bounded machine navigation. Public publication mirrors intentional documentation safely. Current source/tests/runtime remain final authority.
