# AI Agent Decision Tree

## Broken RAG request

1. Preserve production PID, port, live hashes, and open handles.
2. Probe both strict routes with `autoInstall=false`.
3. If route missing, trace registration.
4. If lane missing, inspect root, filename, and fast manifest.
5. If embedding fails, inspect model root, model file, binary, provider, and dimensions.
6. If index fails, inspect list, metadata, registry count, entry node, keys, and payloads.
7. If only derived graph is bad, rebuild it from existing vectors on an isolated candidate.
8. Re-embed only after vectors are proven absent, corrupt, or incompatible.

## Growing database

1. Confirm callers import `index.js`.
2. Confirm omitted reuse resolves to `verified`.
3. Compare omitted, explicit verified, and explicit false on disposable databases.
4. Inspect leases, quarantine, free-list seal, tail ranges, WAL, and allocated blocks.
5. Vacuum only to a separate candidate.

## Completion

Require fresh hashes, strict provenance, cold/warm/restart proof, candidate audit, read-only reopen, tests, documentation freshness, rollback, and an approval gate.
