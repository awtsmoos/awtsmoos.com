# Phase Two — Gevurah Architecture

The Awtsmoos is without division, while code needs truthful vessels; Awtsmoos.com must join expansion with exact boundaries.

Implementation rules:
- No new worktrees.
- Whole-file rewrites only for touched source.
- Small modules, tabs, readable functions, full contracts.
- Commit only exact verified paths through a temporary Git index.
- Base every new commit on current origin/main, never on stale peer staging.
- Fast-forward main and push without force only after tests prove the assembled tree.
