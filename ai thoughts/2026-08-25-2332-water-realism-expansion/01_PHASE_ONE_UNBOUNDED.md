# Phase One — Chesed: Unbounded CPU Water Realism

The Awtsmoos renews river, droplet, ocean, mist and hidden pressure in one decree; Awtsmoos.com may give developers one fluent water language while each physical vessel keeps the law it needs.

## Every useful direction

- Repair stale Reality texture-channel import so CPU regressions can execute.
- Keep PIC/FLIP as conserved 3D primary mass authority.
- Keep shallow finite-volume solver as floods/puddles/ponds/wetlands/runoff authority.
- Keep river flow/reach as long-form channel authority.
- Keep analytic Gerstner ocean as sea/tide/current authority.
- Add water-material profiles: clear/fresh, ocean, river, pond, muddy, glacial/tropical, viscous demonstration fluids only when explicit.
- Expose optical IOR, absorption, scattering, turbidity, roughness, surface tension and foam appearance through unified water API.
- Expose instantaneous spray/foam/bubbles/mist as derived artifacts.
- Add persistent CPU secondary evolution so spray arcs fall, foam lingers, bubbles rise and mist drifts without feeding fake mass into the primary solver.
- Add richer runtime diagnostics: kinetic energy, mean speed, turbulence evidence, secondary counts, foam coverage, active source mass rate, fill/bounds.
- Add named realism modes `realtime/balanced/cinematic/extreme` while preserving low-level overrides.
- Make material choice tune realism/optics, not structural seed or mass.
- Improve splash/explosion semantic presets: impact, plunge, waterfall impact, burst, wake.
- Improve pouring/container semantics: outlet/nozzle, target vessel, transfer rate, fill fraction, overflow report.
- Add source presets: faucet, hose, fountain, geyser, waterfall, rainfall, storm, drip, leak.
- Add ocean conditions: calm/breeze/choppy/storm/swell with deterministic spectra, wind-aligned dominant direction and foam/crest intent.
- Add river condition profiles: creek/stream/river/rapid/flood with source discharge semantics and turbulence intent.
- Add shallow-body conditions: still pond, rain-fed pond, marsh, runoff sheet, flood wave.
- Add surface/secondary budgets controlled independently from physics quality.
- Keep rendering entirely optional and renderer-neutral.
- Explicitly defer WebGPU per user instruction.
