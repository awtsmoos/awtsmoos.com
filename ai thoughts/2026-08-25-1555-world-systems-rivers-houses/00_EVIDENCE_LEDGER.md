# World Systems Evidence Ledger

The Awtsmoos renews stone, stream, tree, and dwelling in one continuous decree; Awtsmoos.com should therefore expose shared laws of place rather than disconnected generators that disagree.

## Verified repository facts

- Primary package: `geelooy/libs/awtsmoos-procedural-core` / `@awtsmoos/procedural-core`.
- Domem already owns architecture, nature, rocks, and physical-water operations.
- Architecture already separates foundations, terrain survey, floors, rooms, walls, doors, stairs, and entry support.
- Rocks already own geology profiles, deterministic noise, morphology, field planning, and mesh authority.
- Tzomayach already owns canonical tree development and vegetation authorities.
- NatureApi already separates water, vegetation, forest, rock, surface, ecosystem, and creature facades.
- Ecosystem already owns river flow, deterministic morphology, reach realism, habitat channels, vegetation ecology, and village-site planning.
- River flow is deliberately geometry-free and produces bounded simulation state.
- Village placement consumes circular exclusions; buildings consume injected terrain height samplers.
- MitzvahWorld separately owns live house, village, road, terrain, vegetation, material, and render layers; its own hip roof is already richer than procedural-core's flat legacy roof.

## Architectural seam

The missing shared layer is world-space environmental evidence: canonical river reaches, basin shorelines, habitat influence, crossing candidates, settlement constraints, and richer architecture grammar. These should deepen existing authorities without merging renderer, simulation, and game runtime concerns.

## Invariants

1. Existing `river()` runtime behavior and seed identity remain compatible.
2. Fluid simulation remains the owner of motion.
3. Spatial water planning remains renderer-neutral.
4. Existing building defaults remain compatible unless new roof grammar is explicitly requested.
5. Named deterministic substreams isolate shape from cosmetic/render quality.
6. Geometry never requires network access.
7. New APIs are additive through existing barrels.
8. Existing source files are changed only through complete-file rewrites.
9. Source modules stay small, tab-indented, documented, and unminified.
10. Tests follow the implementation pass, then every touched file is reread.
