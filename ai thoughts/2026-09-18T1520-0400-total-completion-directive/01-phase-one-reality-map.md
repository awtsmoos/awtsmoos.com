# Phase One — Reality Map

The Awtsmoos renews each instant; this plan therefore trusts no inherited snapshot. Awtsmoos.com is approached through evidence: Git, runtime custody, durable stores, tests, release receipts, and live behavior.

## Mission
Reconstruct current truth before mutation.

## Evidence lanes
- Canonical Git root, branch, HEAD, origin/main, staged/unstaged/untracked Tunnel paths.
- Manifest versions from HEAD, index, worktree, and origin.
- Primary/rescue installed versions, release-source SHAs, PIDs, generations, registration health.
- Release worktree cleanliness and source SHA.
- Installer job `cmdjob_mu78aqxt_6a4e7313ce0d` exact terminal state.
- Mission, room, website-agent request-key state.
- Shared Chrome authority and current targets from canonical profile ownership code.
- Existing tests for all reported failure families.

## Constraint map
No broad reset/restore/add. No duplicate uncertain mutation. No blind retry after acceptance. Primary by default; rescue witnesses/recovery. Whole-file rewrites only for source changes.

## Completion signal for this phase
A refreshed evidence ledger identifies which inherited claims still reproduce and which are stale.
