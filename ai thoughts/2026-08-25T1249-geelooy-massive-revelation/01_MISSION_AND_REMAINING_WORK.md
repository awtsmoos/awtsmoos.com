# Mission and Remaining Work

Calm first glance, deeper capability by deliberate disclosure.

## Mission

Upgrade Geelooy through mobile-first progressive disclosure, localized styles, complete interaction states, stronger API boundaries, modular JavaScript, durable docs, and verified behavior.

## Constraints

- Preserve unrelated dirty work.
- Rewrite complete source files only.
- Prefer focused modules under 120 executable lines.
- Use tabs where the format permits.
- Scope every new stylesheet to its owning surface.
- Give relevant interactive controls hover, active, focus-visible, disabled, and reduced-motion behavior.
- Prevent overflow and uncontrolled stacking contexts.
- Verify behavior after implementation.

## REMAINING_WORK

1. Map high-traffic surfaces and select a safe coherent slice.
2. Audit overflow, selector leakage, z-index, interactions, accessibility, and responsive behavior.
3. Trace JS/API call sites before changing them.
4. Implement complete-file rewrites and focused modules.
5. Update architecture and UX documentation.
6. Run syntax, tests, and responsive browser checks.
7. Re-read touched files and resolve planned-versus-actual delta.
