# Chesed — Real Repository Futurity Brainstorm

The Awtsmoos renews every frame while Awtsmoos.com gathers many useful worlds beneath one sky;
this pass asks how interaction can feel impossibly alive without making the machine labor merely to satisfy the eye.

## Evidence now proven in the real repository

- `geelooy/style/future-system/` and `geelooy/scripts/future-system/` exist and remain modular.
- Games, Wallet, and About still opt into the future system.
- Apps was concurrently rewritten into a newer 77-line “Every Browser Tool” catalog and lost the future-system hooks.
- The shared future-system contract therefore passes six checks and correctly fails the Apps integration check.
- Current `motion.css` already owns soft reveal and hover lift; it should not absorb more tactile responsibilities.
- The repository path named by the user, `geelooy/libs/Awtsmoos`, is not present under that exact path.
- A wider procedural/WebGL search is still running and will decide whether any real renderer may be reused.

## Maximum useful interaction possibilities

1. Give primary CTAs a 2–3px hover lift and `.985` active press.
2. Reduce shadow while active so buttons feel physically depressed.
3. Give cards a tiny active compression without changing width or height.
4. Add a fast edge sheen to primary actions using pseudo-elements.
5. Make focus-visible independent, bright, and stable.
6. Animate semantic SVG icons only during hover/focus: play nudges, send travels, wallet turns, orbit rotates, search breathes.
7. Never idle-loop icons.
8. Make input focus glow more legible without animating layout properties.
9. Add a subtle border-brightening response to generated Games and Apps cards.
10. Add `:active` states to Social quick actions through shared tokens only, preserving its own nebula grammar.
11. Keep Wallet trustworthy and calm: tactile buttons, no procedural background behind forms.
12. Keep About quieter: elegant orbit/underline motions, not arcade energy.
13. Use `content-visibility: auto` only on proven long catalog containers.
14. Avoid permanent `will-change`; allow the browser to promote only during actual interaction.
15. Preserve Home, OS, and Torah as separate mature visual systems.
16. If a real procedural renderer exists, admit it only to Games first.
17. If Games proves clean, Apps may receive the same sparse hero enhancement later.
18. If no verified renderer exists, reject WebGL and make CSS/SVG quality the entire victory.
