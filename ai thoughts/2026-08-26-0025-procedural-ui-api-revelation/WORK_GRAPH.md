# Work Graph

## Goal G0 — A simple-first, advanced-on-demand procedural creation experience

G0 depends on four branches that can be improved independently and then joined through data contracts.

### G1 — Creator UI surface

G1.1 inspect rail markup/view/controller/materials/style architecture — observed
G1.2 install creator-local CSS family — next
G1.3 refine semantic markup while preserving hooks — after installer
G1.4 improve closed/collapsed focus/pointer semantics — after markup
G1.5 verify CSS localization/layers/states — after implementation
G1.6 browser-verify portrait/landscape/desktop geometry — after static verification

### G2 — Shared procedural capability language

G2.1 inspect Nature/domain APIs for rock/tree/grass/flower/creature/texture/water
G2.2 create immutable capability descriptor schema
G2.3 map only capabilities proven by real authorities
G2.4 expose simple catalog/filter/detail API
G2.5 connect creator advanced controls to descriptor data rather than hard-coded feature trees
G2.6 document simple and expert examples

### G3 — Generator quality expansions

G3.1 rocks: geology/morphology/field/preset/API realism
G3.2 trees: species/branching/canopy/roots/cluster realism
G3.3 grass: blades/clumps/coverage/wind/LOD ecology
G3.4 flowers: petal/inflorescence/cluster/ecology variants
G3.5 creatures: body-component grammar/attachments/materials/behavior descriptors
G3.6 textures: local procedural + remote-source abstraction/caching/provenance
G3.7 water: finish pending CPU realism cleanup from prior mission

Each G3 node depends on inspection of existing authority, additive public API, focused tests, docs, and no renderer coupling.

### G4 — Cross-cutting quality

G4.1 source files <=120 lines by splitting responsibilities
G4.2 complete JSDoc and meaningful domain naming
G4.3 tabs/no cramped source
G4.4 no generated bundle hand edits
G4.5 focused tests before broad regressions
G4.6 browser accessibility/geometry checks for UI
G4.7 final planned-vs-actual readback and remaining-work closure

## Critical path

G1.2 → G1.3 → G1.4 → G1.5 → G1.6 → G2.1 → G2.2 → G2.3 → G3 slices.

The Awtsmoos renews the whole graph while finite work moves edge by edge; Awtsmoos.com keeps each node small enough to verify and strong enough to become the foundation of the next revelation.
