# Capability Phase One — Chesed: Every Door the Simple API Could Reveal

The Awtsmoos renews every operation before a catalog can name the way; Awtsmoos.com may let one quiet discovery surface reveal immense procedural power without making ordinary creation verbose today.

## Direct evidence already established

- `NatureApiBase` exposes mature verbs: creature, plant, flora, grass, tree, forest, river, world, biome.
- `NatureDirectApi` adds rock, rockField, rockMorphology, material, generateTexture, surface, generateSurface, flowers, and canGenerateTextures.
- `NatureCatalogApi` is already a registry-backed species/value discovery facade.
- `NatureCatalogDomains` deliberately contains creature, ecosystem, plant, and tree value catalogs.
- `RockNatureApi` already separates geology-first creation, deterministic rock-field planning, and explicit expert morphology.
- Generated textures are already injection-based rather than hidden network I/O.

## Possibility field

A procedural capability record could reveal:

- stable id such as `rock.create`, `vegetation.grass`, `material.generateTexture`;
- family such as matter, vegetation, creature, water, world, surface;
- public verb/path such as `nature.rock()`;
- human label and concise description;
- execution kind: sync, async, plan, runtime, generated asset;
- complexity level: simple, advanced, expert;
- deterministic seed support;
- quality and realism support;
- whether remote/provider capability is optional or required;
- simple input descriptors with defaults;
- grouped advanced inputs for progressive disclosure;
- preset/catalog relationship without duplicating actual preset values;
- output kind and short result semantics;
- aliases only when actual API aliases exist;
- tags for search/filter/docs/UI;
- example request data that can feed documentation and future creator controls.

## Future UI uses

- Creator advanced drawer can ask the capability API what controls exist.
- Mobile UI can show only simple fields until a capability group is expanded.
- Documentation can render the same labels/defaults/grouping.
- Search can find "flowers", "rock field", "remote texture", or "river" without knowing class names.
- Future command palette, voice UI, and automation can consume the same immutable records.

## Explicit non-goals

- Do not execute generation from the registry itself.
- Do not copy specialist preset catalogs into capability metadata.
- Do not hide async/network requirements.
- Do not replace `NatureCatalogApi` species/value discovery.
- Do not rename existing simple public verbs.
- Do not invent fields for APIs not proven by source.
