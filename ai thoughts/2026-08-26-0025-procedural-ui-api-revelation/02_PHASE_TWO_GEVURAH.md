# Phase Two — Gevurah: Constraints, Risks, and Twenty Corrections

The Awtsmoos has infinite possibility while Gevurah gives finite form; Awtsmoos.com uses restraint so futuristic beauty never becomes noisy, fragile, inaccessible, or globally entangled.

1. Do not redesign every HUD at once; prove the localized creator family first.
2. Do not create a second UI state store; existing creator session/view/controller separation is strong.
3. Do not style bare `button`, `details`, `summary`, `small`, `strong`, or `output`; every selector remains rooted under `.Awtsmoos-creator-rail`.
4. Do not use `:root`, `html`, or `body` in shared creator styles.
5. Do not use `!important` as a conflict escape hatch.
6. Do not use arbitrary z-index literals throughout fragments; publish named creator layer variables in foundation.
7. Do not animate width/height continuously; prefer transform, opacity, filter, grid-template-rows only where bounded and purposeful.
8. Closed rail must be non-interactive and non-focusable through presentation/inert semantics, not merely transparent.
9. Collapsed rail must retain the header and restore affordance while its body is truly hidden from layout/focus.
10. Mobile panels must honor safe-area insets and `100dvh`, not legacy viewport assumptions.
11. Palette may scroll internally but must not force horizontal document overflow.
12. Touch targets remain at least practical finger size while short-landscape can reduce spacing, not hit area.
13. Native `<details>` remains the advanced disclosure authority unless evidence proves a custom disclosure is needed.
14. Fancy glow remains restrained and static by default; motion only reinforces state transitions.
15. Focus-visible ring must remain visible above glow and must not be clipped by overflow.
16. Material buttons preserve `aria-pressed`; styling must not make selection color-only.
17. Existing semantic `data-*` hooks remain stable for tests and controller bindings.
18. Generated compact bundles remain untouched; source build pipeline owns them.
19. Procedural capability metadata must point to existing authorities rather than invent APIs that cannot execute.
20. Remote textures must reuse existing asset/texture infrastructure after inspection rather than embedding network fetch logic into rock/tree generators.

## Failure map

- Global CSS collision: prevented by strict root localization test.
- Offscreen UI: prevented by max-inline-size, inset clamping, safe areas, internal scroll, browser geometry tests.
- Z-index chaos: prevented by one foundation layer map.
- Mobile clutter: prevented by collapsed/basic/advanced progressive disclosure.
- Input theft: preserve current controller/view behavior and verify hidden pointer/focus flow.
- API bloat: capability descriptors provide simple defaults and explicit advanced fields from one schema.
- Generator duplication: each feature manifest delegates to existing Nature/domain authority.
- Documentation drift: docs generated/maintained from descriptor vocabulary and examples, not duplicate undocumented option names.
