# Tiferes Final Plan — Harmonized Recovery

The Awtsmoos is beyond every grid and image, yet Awtsmoos.com should let each finite vessel reveal its purpose with beauty, clarity, and truth.

## Thirty final refinements

1. Use production as visual reference, not as unquestioned source truth.
2. Recover historical direct-image URL from browser history before editing UI.
3. Measure every candidate original by native dimensions and byte size.
4. Reject candidates smaller than the current 1024 source.
5. Reject upscaled derivatives when provenance is uncertain.
6. Keep recovered original outside repository storage.
7. Prefer the existing alias filesystem path so HTML stays environment-neutral.
8. Diagnose local alias zero-byte response before changing API source.
9. Inspect response code and headers from local alias endpoint.
10. If data is missing, restore data; if code is broken, only then repair code.
11. Use a blank Chrome target for controlled local verification rather than disturbing user tabs.
12. Hard-navigate that target to port 8080 to defeat stale page state.
13. Measure hero `currentSrc`, natural size, and rendered size.
14. Measure document scroll height versus viewport height.
15. Measure featured-section top/bottom against viewport.
16. Measure computed opacity/visibility/display/transform.
17. Measure `.is-revealed` state and root `.has-reveal-motion` arming.
18. Preserve production-matching feature-card CSS unchanged.
19. If reveal is the problem, rewrite `reveal-motion.css` as progressive enhancement.
20. Keep all content visible before `.has-reveal-motion` is applied.
21. Arm hidden starting states only after controller initialization is guaranteed.
22. Ensure reduced-motion users always see content immediately.
23. Restore production’s stronger “Four powerful ways into Awtsmoos” heading if local copy feels weaker.
24. Keep the lower grid visually separated with breathing room so scrolling feels intentional.
25. Keep four cards at desktop, responsive below, without duplicate navigation.
26. Update fold contract tests for four feature cards and progressive reveal safety.
27. Add a lightweight runtime assertion for non-empty hero response when feasible.
28. Re-read every rewritten source file in full.

30. Finish only when image provenance, grid visibility, and live/local comparison all have evidence.
