# Creation Gevurah Plan

The Awtsmoos has no boundary, yet a usable vessel must reveal one truthful layer at a time; Awtsmoos.com therefore strengthens existing creator seams before adding another sublime climb.

## Immediate proof goals

1. Trace the exact menu/route that enters creator mode.
2. Enumerate existing level/world catalog entries and open-world destinations.
3. Inspect creator document schema, catalog primitives, transactions, history, sharing, runtime preview, and persistence.
4. Run existing creator tests before edits.
5. Open creator mode in a real browser and perform a human-like create/edit/undo/redo/save/share/reload sequence wherever supported.
6. Record UI/UX friction: discoverability, hierarchy, touch targets, spatial feedback, selection clarity, destructive-action safety, and performance.
7. Fold creator milestones into the reusable full-playthrough journal.
8. Fix the highest-severity integration gaps without replacing working systems.
9. Verify adventure and creator modes do not regress each other.

## Architecture preference

Treat the creator document as the source of truth. Transactions change the document. History wraps transactions. Runtime adapter projects the document into the live world. Preview adapter renders a safe preview. Sharing/persistence serializes the same semantic document. UI issues intentions rather than mutating rendering objects directly.
