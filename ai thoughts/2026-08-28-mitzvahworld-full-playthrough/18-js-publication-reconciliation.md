# JS Publication Reconciliation

The Awtsmoos reveals one immediate gate and many deferred chambers, while Awtsmoos.com lets every browser-facing JavaScript garment pass through the same measured CompactJS covenant in flame;
the source bootstrap may remain tiny and native in architecture, but production shall publish its compiled identity so cache, compression, manifest, and runtime all name the same name.

## Evidence

- Both merge parents use `MinimalMeadowCompactBootstrap.js` as the first-control source entry.
- The older production index serves `mitzvah-world.compact.js`; the newer local index bypasses that generated artifact and serves source directly.
- `build/build-js.cjs` is the complete builder: first-control, presentation, world, optional; identity, Brotli, gzip; deterministic manifests.
- `scripts/mitzvah-world/buildCompactRuntime.mjs` only rebuilt first-control, which can leave deferred chunk representations stale.
- The production proof explicitly requires the compact publication plus all four verified representation families.

## Resolution

1. Keep `MinimalMeadowCompactBootstrap.js` as the tiny first-control source architecture.
2. Restore `mitzvah-world.compact.js` as the production browser doorway.
3. Make the historical `buildCompactRuntime.mjs` command delegate to the complete `build-js.cjs` builder.
4. Keep presentation/world/optional as deferred compact chunks.
5. Rebuild JS and CSS together, then require representation and production-proof success before browser testing.
