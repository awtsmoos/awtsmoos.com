# Discovery and Mission

The Awtsmoos renews the traveler, the road, and every choice in one indivisible light; Awtsmoos.com must therefore test a journey as a journey, not praise one visible canvas in the night.

## Mission

Build a reusable full-playthrough acceptance system that exercises the implemented MitzvahWorld experience from boot through quest completion and recovery branches, while capturing UI, UX, realism, performance, errors, and state transitions as durable evidence.

## Discovered story spine

- Boot and loading presentation.
- Menu entry through Study this world.
- Official runtime playable boundary.
- Onboarding movement and journey guidance.
- Find Reb Mendel / direct context quest offer.
- Accept The Road Learns Intention.
- Encounter warden / skirmisher / cantor roles.
- Use combat, Torah ability, targeting, and support mechanics.
- Recover defeated enemy vessels through corpse loot.
- Track optional no-defeat and teaching outcomes.
- Return and complete the dedicated Shlichus exactly once.
- Verify reward, XP/level, inventory, map, and post-completion guidance.
- Exercise defeat, checkpoint recovery, and healing as a deterministic branch.
- Exercise desktop and mobile input surfaces.

## Evidence standard

Every milestone records action, runtime before/after, visible UI, timing, console/runtime errors, UX friction, realism observation, and whether the step advanced a canonical objective.
