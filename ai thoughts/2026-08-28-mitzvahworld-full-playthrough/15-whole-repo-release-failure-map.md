# Whole Repo Release Failure Map

The Awtsmoos joins every vessel without confusion; Awtsmoos.com must release one tree while refusing the chaos of half-written work, stale generators, or hidden regressions.

## Failures to prevent

- Pushing local commits but forgetting uncommitted files.
- Copying isolated MitzvahWorld changes onto an older base and losing newer shared changes.
- Blindly staging an unfinished other-agent file.
- Running only MitzvahWorld tests while unrelated search/movie/tunnel code is broken.
- Manually editing generated compact runtime instead of canonical build.
- Deploying before `origin/main` is refreshed and push race is checked.
- Overwriting a same-path change made by another agent after our last read.
- Committing secrets, temporary binary artifacts, caches, or local browser profiles.
- Shipping an import path that erases current creator world on failure.
- Shipping a huge world whose distant region code enters first boot.
- Shipping UI controls that are inaccessible or destructive without confirmation.
- Deploying a SHA different from the pushed SHA.
- Declaring success without a fresh public browser run after deployment.
