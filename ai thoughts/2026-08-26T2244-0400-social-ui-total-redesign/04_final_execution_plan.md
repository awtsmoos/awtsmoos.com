# Final Execution Plan — Reveal, Simplify, Verify

Boruch Hashem. Blessed is He.

The Awtsmoos.com interface will be rebuilt from evidence: each visible layer must justify its presence, each action must know its rank, and every mobile width must retain a clear path from intent to publication.

## Phase 1 — Reveal actual architecture

1. Locate the `social-composer` route and exact text seen in the screenshot.
2. Map its HTML/JS/CSS/component imports and direct dependencies.
3. Inspect the current browser DOM at the live screenshot route.
4. Identify social-global styles and adjacent routes sharing the same primitives.
5. Record dirty-state ownership for every candidate target file.

## Phase 2 — Design contract from real files

6. Define the simplest component hierarchy supported by current behavior.
7. Decide which panels collapse on narrow screens.
8. Define local social tokens for surfaces, spacing, type, controls, layers, and semantic states.
9. Identify files that must split to respect the 120-line vessel law.
10. Write an exact file-touch map before source mutation.

## Phase 3 — Whole-file implementation

11. Rewrite complete target files only.
12. Make the editor primary and preview secondary/collapsible.
13. Replace nested visual boxes with real sections and spacing.
14. Reduce button/pill proliferation and establish explicit action hierarchy.
15. Demote destructive actions into intentional secondary flows.
16. Localize styles under social/component roots.
17. Implement mobile-first responsive behavior and semantic layers.
18. Preserve behavior contracts while simplifying information architecture.

## Phase 4 — Verification

19. Read every rewritten file completely.
20. Run syntax/unit/build checks relevant to touched modules.
21. Launch/navigate the real local page.
22. Inspect 320, 375, 430, 768, 1024 and desktop widths.
23. Check overflow, focus, keyboard, touch, drawers, sticky regions, and reduced motion.
24. Capture browser screenshots at the exact 430px route and at desktop.
25. Compare user-visible hierarchy against the original screenshot.

## Phase 5 — Continue across social system where evidence supports reuse

26. Find adjacent social pages sharing the same clutter-causing styles/components.
27. Migrate shared primitives without broad global leakage.
28. Verify each affected page live.
29. Update REMAINING_WORK with true residual issues only.
30. Re-read plans, compare planned versus actual, and close the completion gate with evidence.
