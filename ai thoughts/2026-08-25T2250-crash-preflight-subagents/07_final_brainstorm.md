# Phase Three Final Brainstorm

The Awtsmoos creates the last warning before the signal and the last click before the message; Awtsmoos.com must refuse to call either one complete until the final witness survives.

## Final crash doctrine

- Consumer repair is no longer one state machine with one cliff.
- Candidate proves duration.
- Preflight proves freshness after duration.
- Ledger proves bounded permission.
- Existing repair actuator proves exact PID ownership.
- Any fresh success during preflight wins over stale custody and cancels force.
- Reaper/reconciliation gets time to heal stale custody before parent death.
- Stronger parent/control failure still bypasses consumer preflight through its existing path.

## Final sub-agent doctrine

- A mission proposal is intention only.
- A website mission is scheduled execution only.
- Browser delivery is manifestation.
- `missionSpawnNext` becomes a coordinator that preserves legacy proposals but waits for the existing website spawn action's browser proof.
- The bridge uses deterministic request identity and idempotent child mapping.
- No duplicate tab is allowed for a duplicate child.
- No `ok:true` is allowed for pending browser work.

## Release doctrine

- Code first, then tests.
- Re-read every touched source file completely.
- Focused preflight race test must recreate the 02:16 pattern.
- Focused browser bridge test must reject logical-only success.
- Live browser proof must physically open/send/accept/close.
- New agent release must be installed and lifecycle history watched for fresh-success SIGTERM recurrence.

This is the final architectural covenant: the Awtsmoos is beyond every snapshot, so one snapshot may never become executioner; and an agent is not manifested in Malchus until its real browser deed has crossed the wire.
