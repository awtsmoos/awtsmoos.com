# Phase Two Critique — Twenty-Four Improvements

The Awtsmoos creates both warning and rescue anew; Awtsmoos.com therefore lets each safeguard be judged by whether it prevents harm without becoming harm.

1. Separate stall detection from repair authorization.
2. Add a post-maturity preflight window before the ledger claim.
3. Require at least two preflight observations, not one stale frame.
4. Cancel preflight on any fresh execution success.
5. Cancel preflight on runtime pressure/backpressure.
6. Cancel preflight if consumerStalled becomes false.
7. Cancel preflight if corroborating ingress/stage/orphan evidence disappears.
8. Preserve the original stall reason through claim and signal logs.
9. Store claim outcome separately from repair reason.
10. Reset candidate and preflight after every claim attempt.
11. Keep ledger cooldown/rate-limit behavior unchanged.
12. Never let one stale orphaned custody record outweigh fresh success.
13. Prefer reaper/reconciliation for old custody before parent death.
14. Expose preflight state in watchdog snapshots for diagnosis.
15. Add the exact 02:16 race as a regression: mature stall then fresh success before signal.
16. Add a true-stall regression proving repair still happens after preflight.
17. Keep parent/control-unresponsive recovery independent and stronger.
18. Keep connection-child-only recovery independent from parent repair.
19. Make mission child-to-browser mapping deterministic from mission/child IDs.
20. Reuse the existing website spawn path rather than duplicating browser logic.
21. Make missionSpawnNext success depend on browserDelivery.ok for every requested child.
22. Preserve pending/failed child delivery diagnostics rather than hiding them.
23. Make duplicate missionSpawnNext calls reuse stable website mission/request keys.
24. Prove physical target open/send/POST/close live before release.

A safeguard is Gevurah only when it protects; when it destroys fresh work it has crossed its boundary. Tiferes is the second look before force, and Malchus is the browser receipt that proves an agent truly arrived.
