# Phase One — Broad Tunnel Brainstorm

## Architectural possibilities
- Treat transport, execution, mailbox, queue, control, and browser proof as independent health dimensions.
- Preserve exact deed identity across server relay, native ingress, mailbox custody, command jobs, and retry wrappers.
- Make destructive parent repair a bounded state machine with sustained evidence, fresh preflight, durable claim, exact PID/generation target, and immediate veto on fresh progress or pressure.
- Add reconciliation-first stale-custody recovery: terminal evidence wins; ambiguous execution remains quarantined from redispatch; only proven non-execution can be safely reclaimed.
- Reserve independent control/recovery capacity outside user-work lanes.
- Make queue telemetry stateful enough to identify reservation, dispatch, acceptance, consumer start, execution, and terminal delivery separately.
- Make command job start a reservation-and-receipt operation; output observation must never consume execution admission.
- Reconcile late native completion into effective operational truth while retaining timeout history.
- Make browser sub-agent success depend on physical target, composer write, Send, accepted conversation request, close verification, deterministic dedupe, and durable mission state.
- Make mission-room messaging a durable directed protocol with sender, recipient, message identity, acknowledgement, and parent visibility.
- Make docs structured records with ids, tags, paths, actions, examples, failure modes, recovery, and related documents.

## Failure families to hunt
Transport flaps; upstream 502; stale telemetry; parent false-positive kill; mailbox custody leak; outbox loss; reservation leak; requester unfairness; command start blocking; retry identity mismatch; late completion hidden by timeout; duplicate mutation; browser tab duplication; send without acceptance; acceptance without close; mission message loss; manifest drift; release SHA mismatch; branch/worktree loss.

## Evidence requirements
Every proposed fix needs a reproducer or direct trace, a focused test, integration evidence, and live proof on the native Mac.
