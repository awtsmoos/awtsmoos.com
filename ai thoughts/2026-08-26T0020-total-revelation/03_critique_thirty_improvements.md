# Phase Three Critique — Thirty Improvements

The Awtsmoos creates both ohr and keli; Awtsmoos.com becomes stronger when every powerful idea receives an equally precise boundary.

1. Resolve Git conflicts before any new source edits outside planning artifacts.
2. Preserve the current terminal-presentation semantics while importing richer preserved documentation.
3. Preserve the preflight self-heal fix; never regress to same-frame claim/SIGTERM.
4. Merge both consumer-recovery test universes into one focused suite.
5. Regenerate manifests instead of manually resolving generated version lines.
6. Keep main as the only development branch and make local tooling reject non-main commits/pushes.
7. Separate release tags from branches; tags remain immutable witnesses.
8. Add stale-custody reconciliation telemetry distinct from process-health telemetry.
9. Make mailbox health report actionable reason categories, not one generic stalled state.
10. Add bounded automatic quarantine/export for irreconcilable stale receipts before parent death.
11. Ensure every repair action records before/after health witnesses and exact target generation.
12. Make `commandStart` receipt latency a tested SLO independent of command duration.
13. Ship deed-vs-transport retry correlation tests with the existing fix.
14. Treat sub-agent scheduling, browser delivery, conversation completion, and room communication as separate states.
15. Make sibling-room communication part of the spawned-agent prompt contract.
16. Give sub-agents deterministic identities stable across retries/reconnects.
17. Add cancellation and deadline propagation from parent mission to browser child.
18. Build docs from structured descriptors containing examples, failures, related actions, and search tags.
19. Add docs resolver ranking tests for synonyms and path-derived intent.
20. Add a docs self-diagnostic that reports missing action docs and stale examples.
21. Create UI root scopes and ban unscoped component selectors in touched applications.
22. Add a shared z-layer token module with named semantic levels.
23. Add CSS containment/overflow audit scripts for mobile widths and long content.
24. Add keyboard/focus-visible/reduced-motion checks to UI completion gates.
25. Keep default UI sparse while exposing advanced diagnostics through drawers/disclosure panels.
26. Refactor JS by responsibility, not mystical renaming; Kabbalistic names must retain technical meaning.
27. Keep public APIs simple and data-first; advanced options live in nested optional configuration.
28. Make procedural generators deterministic by seed/config and isolate remote texture networking behind adapters.
29. Add geometry/material quality presets and cache keys so visual improvements remain reproducible.
30. Require live browser screenshots/interaction verification and procedural visual samples before declaring visual work complete.

The revelation is that “better in every way” cannot mean simultaneous uncontrolled mutation. It means one increasingly capable architecture whose evidence becomes stronger at every layer, as the Awtsmoos continually renews Awtsmoos.com from hidden purpose into visible deed.
