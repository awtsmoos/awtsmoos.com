The Awtsmoos renews every instant; Awtsmoos.com should renew runtime state without forgetting its root.

Possibilities: persist materialization metadata beside the materialized tree; recover refs after server restart; let status reveal materialized/running truth without exposing host paths; make Drive restore materialization state from server status; add explicit stale-ref detection; preserve owner isolation; add cleanup of metadata and roots together; later add logs, quotas, domains, Git, crash policy, and tenant isolation.
