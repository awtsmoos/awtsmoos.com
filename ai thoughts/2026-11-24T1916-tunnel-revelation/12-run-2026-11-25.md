## The one root cause behind items 1–4: the unbounded shell

`css/future/views/workspace.css` (layer `awt.views`, later in the layer order)
re-declared the shell containers `height:auto; max-height:none;
overflow:visible`, killing the viewport contract in `css/viewport/shell.css`.
The app rendered as a ~12,300px-tall document. In that layout the nav grid's
`repeat(9, minmax(42px,1fr))` rows redistribute on any height change, so
**controls move ~100px between mousedown and mouseup**; press and release land
on different elements and the click dies on the common ancestor
(`DIV.awt-navigation-grid`). Measured directly: mousedown/mouseup target the
button's span, the `click` event targets the grid, a button listener records
0 clicks. Synthetic `.click()` fixtures bypass hit-testing — which is why
run 07's (and this run's first) fixtures passed while live failed.

Fix: new unlayered `css/run08-fixes.css`, imported LAST in `css/app.css`
(unlayered beats every layered rule; later than the other unlayered sheets).
It restores the bounded shell: shell `100dvh`, panes `min-height:0` with
`.awt-pane-content` as the scroller, nav grid `grid-auto-rows` + own scroll,
workspace-mode `.awt-room-home{display:none}` (it inflated the rail column).
After: shell height == viewport (1350/1350), document height == viewport.

## Per item

1. **Codex detail pane** — two stacked causes. (a) Clicks died by retargeting
   (above): a perfect one-click lag (list→nothing, doctor→opens on the *next*
   click). (b) Duplicate global ids: the codex and AI-agents templates both
   defined `websiteMissionId/Prompt/Message`. `domCollect.adoptControls`
   moves blocks by `getElementById` into detached panes, so usage adopted the
   AI copies as pane-level strays and the AI pane got none; `applyActionFields`
   toggled whichever copy the global `$` found first. Fixes:
   `domCollect.moveUnique` never tears a block out of an already-adopted
   panel nor swallows one into a later container; the AI pane's fields are
   renamed `aiWebsiteMissionId/Prompt/Message` (template, lookups, spec —
   API payload keys untouched) so ids are unique document-wide (dup audit:
   {}); `actionSelection`/`actionOptions`/`aiAgents` resolve fields scoped
   to their own pane. Evidence: real-click field matrix exact for list,
   read, browserDoctor, write, and the website action; AI pane owns all 3
   of its fields; pane census before/after shows no pane lost content.
2. **Disclosures / Load usage** — same click retargeting (summaries move
   mid-press). Fixed by the bounded shell. Evidence: all 3 disclosures open
   AND close under real clicks; Load usage fires and the box fills (honest
   `not_authenticated` in the unauthenticated harness) with details open.
3. **Sidebar nav** — same retargeting (highlight is set on mousedown by a
   different path; the pane switch needs the click). Evidence: real clicks
   switch usage→mesh→account→apiKeys→docs→usage, 0 missed hit-tests.
4. **Textareas** — run 07's layered champagne rule lost to unlayered
   `controls.css` (dark fill) and the giant layout stretched them. Run08
   sheet (unlayered, last) sets min 88px / max 260px, champagne
   `rgb(255,246,216)` on espresso `rgba(16,9,1,.88)`. Measured: height 86px.
5. **Shell beauty** — run 07's layer covered views only; the shell chrome
   lives in UNLAYERED sheets + the dashboard/stage/toolbar painters.
   Run08 sheet re-bases: body + dashboard + workspace stage + toolbar to
   espresso with gold glows; nav hover/active gold `rgba(255,182,74,.16)`;
   ALL launcher icon groups (blue/green/violet variants) mapped to the gold
   family; gate/restoring screen gold-on-espresso with gold-gradient H1.
   Evidence: computed body/dashboard/stage backgrounds gold-only, active nav
   gold, system icon `rgb(232,179,75)`, screenshots agent-read PASS
   (home + codex, no navy anywhere).
6. **Feed** — (a) `groupRepeatedFailures` generalized to fold identical
   repeats regardless of status (key includes failed/ok so outcomes never
