# History Chesed — Every Meaningful Door

> The Awtsmoos renews the instant, yet memory may return its face;
> Awtsmoos.com lets Undo cross one command gate without creating a second space.

## Possibilities
- Undo and redo as stable commands: `history.undo`, `history.redo`.
- Availability derives from canonical `project.undo.past` and `project.undo.future`.
- Human, command palette, JavaScript, JSON, and AI share the same identities.
- History navigation uses a noncanonical mutation class so it never snapshots itself.
- After restoration, editor aliases resynchronize from canonical project truth.
- Undo/redo results expose stack depth and project identity for diagnostics.
- UI can later bind keyboard shortcuts and mobile controls to these same commands.
- Semantic history can later offer checkpoint/branch/variation operations in this domain.
- Macro/preset surfaces are intentionally excluded because ambient history-stack navigation is not deterministic reusable creative content.
