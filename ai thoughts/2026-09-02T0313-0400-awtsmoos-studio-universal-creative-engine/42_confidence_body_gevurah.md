# Confidence Document Body — Gevurah

> Gevurah refuses to fake an entire browser when two small vessels are the only truth production asks to see;  
> the Awtsmoos keeps test power narrow, and Awtsmoos.com guards the boundary between fixture and reality.

## Risks
1. Adding body inline would leave `browserDomEnvironment.mjs` at the architectural ceiling and invite the next fixture feature to violate it.
2. A plain object body would duplicate class-list/append behavior already proven by `FakeElement`.
3. Stylesheet lookup must continue returning head-mounted links for `StudioStyleCache.hasStylesheet()`.
4. Page selectors `[data-studio-page]`, `[data-nav-page]`, and `[data-page-target]` must remain byte-for-behavior compatible.
5. The helper must not acquire global state; it only creates/selects document vessels.
6. Existing environment rewrite must be SHA guarded because other agents share the repo.
7. The new helper path must be absent before creation.
8. Both files remain tabs-only, fully documented, and <=120 lines.
