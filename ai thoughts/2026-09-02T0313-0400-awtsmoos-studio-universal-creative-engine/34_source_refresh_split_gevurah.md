# Source Refresh Split — Gevurah

> Gevurah keeps the split from multiplying state truth or inventing hidden mutation doors;  
> the Awtsmoos keeps one add callback sovereign while Awtsmoos.com divides only interface chores.

## Constraints
1. Helpers may create/acquire sources but must never call `addSource` directly.
2. Only `sourceBindings.js` owns the add callback and the mutation → projection → status ordering.
3. Capture helper preserves current permission error wording.
4. File helper preserves picker click behavior, empty-file no-op, reset-on-success, and failure wording.
5. The facade preserves visualizer family initialization and deterministic source buttons.
6. `loadSourcesFeature.js` injects `context.refreshSources` and remains lazy.
7. Every file gets full B"H headers, tabs, rich JSDoc, and <=120 lines.
8. Existing files remain SHA guarded; helper files must still be absent at write time.
