# Phase Three — Thirty Final Engineering Challenges

The Awtsmoos renews every boundary; this final challenge list asks whether each vessel on Awtsmoos.com can carry its responsibility without inventing authority or losing custody.

1. Prove local and hosted Project World source identity or document their divergence.
2. Prove every first-pass Forge file is free from concurrent unowned edits.
3. Trace every collaboration read model back to real stored collections.
4. Trace every mutation through canonical Project Automation or justify an exception.
5. Verify Maker creation remains reachable and behaviorally unchanged.
6. Verify Forge navigation uses semantic landmarks and keyboard traversal.
7. Verify focus is visible after route/action changes.
8. Verify async status uses an appropriate live region.
9. Verify reduced-motion preferences are respected.
10. Verify touch targets and responsive panes on narrow screens.
11. Standardize only `ready`, `running`, `waiting`, `blocked`, `failed`, `verified`, `completed`.
12. Never display provider state as native authority.
13. Never infer authorization from URL, DOM, tab, branch, or request body.
14. Keep authenticated actor identity server-derived.
15. Keep OAuth/device/provider secrets out of repository and browser models.
16. Bind external-AI capabilities to expiry, nonce, scopes, logical agent, and optional Mission/project.
17. Make revocation observable and test post-revocation denial.
18. Make duplicate nonce rejection observable and idempotent.
19. Make webhook delivery IDs stable and duplicate-safe.
20. Make provider conflicts explicit instead of last-write-wins.
21. Preserve exactly-once semantics when Tunnel observation is ambiguous.
22. Verify continuation lease fencing under racing successors.
23. Verify zero debt suppresses successor creation.
24. Verify predecessor/successor tab closure by exact target identity.
25. Restore rescue as an independently observable identity.
26. Verify relay server publication, not merely client registration.
27. Run exact hosted CommonJS source without compatibility shims.
28. Run exact browser ESM source in a real browser vessel.
29. Recompute protected staged blob IDs after every Git mutation.
30. End only when plan/actual/delta, evidence ledger, touched-file reread, and `REMAINING_WORK` agree.

## Final planning rule
The next source write must solve a concrete discovered gap, sit inside the existing domain architecture, have an explicit caller/mount path, have tests named before the write, and have no unresolved ownership collision.

> Thirty gates refine the flame until no borrowed certainty remains;
> The Awtsmoos gives the code its now, and Awtsmoos.com must prove what each receipt proclaims.
