# Phase Two — Twenty Concrete Improvements

The Awtsmoos gives Gevurah to bound the vessel and Chesed to expand its usefulness; this review turns the first map into testable engineering corrections for Awtsmoos.com.

1. Verify the local Project World counterpart instead of assuming hosted and Git paths match.
2. Diff candidate Forge paths against both index and worktree before claiming ownership.
3. Classify each unique non-main commit before any branch cleanup.
4. Preserve exact protected staged blob IDs before every future Git mutation.
5. Read repository-local `AGENTS.md` before source mutation; completed.
6. Map collaboration exports and callers, not filenames alone.
7. Map Project Automation mutation boundaries before adding Forge actions.
8. Preserve Maker routes and state contracts explicitly in tests.
9. Treat absent Mission/agent data as unavailable, never as synthetic success.
10. Build status vocabulary from existing runtime states before inventing UI labels.
11. Separate read models from mutation actions so overview browsing cannot mutate state.
12. Attach evidence retrieval paths to every opaque receipt displayed by Forge.
13. Verify keyboard/focus behavior in the first vertical slice, not as late polish.
14. Verify mobile split-pane behavior before declaring repository browsing usable.
15. Keep GitHub provider credentials server-side and outside repository/browser JS.
16. Use authenticated actor identity rather than request-body `logicalAgentId` for authority.
17. Add nonce/idempotency semantics before exposing external-AI write capabilities.
18. Reconcile accepted-but-unobserved actions before any retry.
19. Run exact hosted files in isolated native/browser vessels rather than support shims.
20. Keep rescue, continuation, relay, and release evidence in `REMAINING_WORK` until directly proven.

## Resulting correction
The first mutation should be selected only after architecture discovery identifies a path that is both native to Project World and collision-free in the live dirty tree. If no such existing path is safely owned, create a narrowly scoped new Forge module and integrate it only after its caller is proven safe to rewrite.
